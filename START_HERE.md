Фразы «исполнение не разрешено» описывают прежнюю дату подготовки, заменены текущим разрешением в корневом STATE. `STATE_PLANNING_ORIGINAL.json` — исторический исходник, не текущие статусы. `MANIFEST_SHA256.json` — манифест исходного вложения: его `STATE.json` соответствует этому историческому файлу, а не корневому STATE.

После блока: commit в этой ветке, актуализированный STATE, конкретные проверки, ограничения и next_action; пользователю дать ссылку Git. Новую игровую сборку и ZIP для одного документационного блока не делать. Не выдавать контроль кода за сохранение личных данных.
