# MOB-04 boar candidate — adapted artwork

Source: [Boar enemies](https://opengameart.org/content/boar-enemies) by Danimal. Original boar model: Myname. The source page additionally credits Clint Bellanger; that credit is retained. This adaptation selects only the unarmoured boar mesh and its rig, excluding all riders and other characters.

License: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). Full legal text is included in `CC-BY-SA-4.0-legalcode.html`.

Adaptation for VARENDOR: modern material conversion using the packed original fur image; source subdivision retained; thin cheek flaps replaced with closed skin; tall mane replaced with short skinned bristles; thick skinned ears, eyes and cloven hoof geometry added; source rider meshes removed; rig weights normalized. Model normalized to 0.8 m height and floor origin. Source idle, trot, attack and death retained with declared timing changes. Walk uses a slowed source trot; run uses the source NLA timing, not a new gallop. Hit is an authored local spine/head recoil. Source idle/trot end/start residual is closed smoothly across the cycle to eliminate a roughly7cm source foot seam. Ground corrections are baked into the adapted clips. Details are in `ADAPTATION.json`.
