# Городской образец P2

Изолированная сцена `city_sample.tscn`: один дом, одно воротное здание, два полностью собранных NPC и участок мощения. Существующие main/world/server не меняются. Запускать Godot 4.6.3 только через scripts/godot_run_checked.py с отдельным выходным каталогом. WASD — свободное перемещение камеры; Q/E — высота. Для автоматических кадров передать `-- --city-output=<absolute-directory>`.

`scripts/city_actor_adapter.gd` создаёт NPC штатной `VarendorWorld.make_actor` по роли `guard` или `resident`. Имена и paths новые. У обоих только авторская idle; запуск боевого/патрульного NPC без дополнительных анимаций не поддержан. Collision моделей статический trimesh для пробы; интегратор отдельно калибрует игровые препятствия и навигацию.

Лицензии в `CREDITS.md`, подробный отчёт и фактические кадры в `docs/world-expansion-v3/P2_CITY_SAMPLE_RU.md` и `P2_CITY_VISUAL_REVIEW.html`. Статус: visual candidate, художественная приёмка открыта.

Наши изменения воспроизводятся скриптами [scripts/assets/city](../../../../scripts/assets/city/README_RU.md): исходники закреплены SHA-256, параметры задаются явно. Дом и ворота приняты как основа; NPC пока остаются телами в одежде с idle.
