# P2 city sample — sources and changes

All five GLBs used in this isolated scene are derivatives of CC0 assets. Attribution is retained for provenance.

- `P2_housepack.glb`: Daniel Andersson, [Medieval House Pack / House 1](https://opengameart.org/content/medieval-house-pack), CC0. Source `75519_House1Upload_blend.zip`. Preserved source geometry and UVs; recovered packed diffuse images and replaced one missing linked Wood material with the included Wood image; built Principled materials with constant roughness; recolored blue window textures to dark amber; normalized horizontal origin/floor. Source door height about 2.07 m retained, scale 1.0.
- `P2_gatehouse.glb`: Daniel Andersson, [Medieval Gatehouse](https://opengameart.org/content/medieval-gatehouse), CC0. Source `76122_GateHouse2Upload_blend.zip`. Recovered packed diffuse images; reconstructed materials, normalized origin/floor. Source scale 1.0 retained (doors about 2.24 m). The sample scene raises separate grilles 2.4 m. It is one gate building, not an entire castle kit.
- `P2_guard.glb`, `P2_resident.glb`: [MakeHuman MPFB](https://github.com/makehumancommunity/mpfb2), [core system assets](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html), CC0 graphics. MakeHuman Community; core attribution includes Data Collection AB, Joel Palmius and Jonas Hauquier. Blender addon code is separately licensed GPL and is not distributed inside the GLBs.
- Guard tunic, trousers and boots; resident boots: Rehman Polanski, [suits02](https://static.makehumancommunity.org/assets/assetpacks/suits02.html), individual `.mhclo` headers CC0. Resident robe: Donitz, same CC0 pack. Only these selected clothes are included, not the entire thematic pack.
- NPC changes: authored body proportions, fitted complete skin/eyes/brows/hair/clothing, supplied game_engine rig and interpolated garment weights, baked body shape keys, removed skin covered by garments, corrected opaque versus masked material modes, compacted textures to 1024 px maximum, added authored four-second breathing/head-glance idle. No source walking or combat clips are claimed. No generative AI assets or AI image editing used.
- `P2_crate.glb`: [Poly Haven wooden_crate_01](https://polyhaven.com/a/wooden_crate_01), CC0, reused from the project's existing licensed copy. Embedded source PBR maps and normalized floor/0.72 m height. Existing Poly Haven cobblestone maps under `res://world-final/castle/` are reused for the floor.
