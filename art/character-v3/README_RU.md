# Промежуточные исходники рыцаря v3

Это сохранение незавершённого блока прыжка, спокойной стойки и цельного комбо. Оно не является готовой Windows-сборкой или визуальной приёмкой. См. [STATUS.md](STATUS.md).

## Восстановление

Из корня клона `work/character-art-v3`, с Python 3.11+ и Git:

```sh
python scripts/restore-character-v3-checkpoint.py
```

Скрипт использует только файлы текущего клона. Он проверяет SHA-256 принятой базы, частей изменений и полностью восстановленных результатов. Не требует LFS, сети, пересборки Blender или платной квоты.

- `art/character-v3/restored/Varendor_Knight_Motion_v3.blend` — 104 507 124 байта; SHA-256 `7de8563656aa5d31f86a8296dc344f969ad38b31ec90645875e78a10dc0a2ca2`.
- `godot-pc/assets/knight/Knight_Modular.glb` — 84 518 416 байт; SHA-256 `d3ca4d70be8b23d37cab23eb10f94be77fbb9261f08bfe6180dfc51839089166`.
- `art/character-v3/restored/Textures/` — 30 отдельных исходных текстур v2. Все 30 изображений также упакованы в `.blend`, поэтому старые пути авторов внутри исходника не мешают его открытию.
- Исходный архив v2 остаётся в `qa-artifacts/pc-build/Varendor_Knight_Modular_v2.zip`: 307 583 888 байт, SHA-256 `532fa1bd023e4e5d9e8a9dc8fecbcf5aeea42d1314df4fd7d0d009d573a699de`.

## Способ хранения

Принятые файлы v2 уже лежат в обычном Git частями по 8 388 606 байт, с манифестом `art/knight-v2/assets-manifest.json`. Они сохранены без изменений. `checkpoint-assets.json` и `payload/` содержат точные прямые бинарные Git-патчи относительно этой базы. Повторное применение даёт исходные байты `.blend` и GLB, включая геометрию, веса, скелет, материалы и анимации; это не конвертация качества и не повторная генерация по рецепту.

Каждая новая часть не больше 262 144 байт. Результаты восстановления игнорируются Git, а необходимые данные для их получения находятся в коммите. Бэкапы, дампы, личные журналы и сборки сюда не входят. `build_motion.py` также сохранён, но для восстановления контрольной точки запускать его не нужно.

Старый `scripts/materialize-knight-assets.mjs` специально оставлен прежним. Если запускать его, затем повторно выполнить восстановление v3. Подключение v3 к окончательной сборке Actions, дальнейшие правки анимаций и игровая проверка — оставшаяся работа основного блока.
