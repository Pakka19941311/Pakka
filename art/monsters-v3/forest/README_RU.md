# Хозяин Гнилого Леса

Утверждённый Forest Monster автора CDmir / Čestmír Dammer. Лицензия CC0, адрес и контрольная сумма исходного архива — `source-lock.json`.

`scripts/build-forest-monster.py` открывает настоящий Blender-исходник с отключённым выполнением встроенных скриптов, сохраняет авторский скелет и шесть анимаций, переводит материалы в Principled с исходными текстурами и маской листвы, исправляет некорректную геометрию, нормализует четыре наиболее сильных веса каждой вершины. Результат — редактируемый `ForestLord.blend` с упакованными текстурами и `ForestLord.glb` для Godot. Видимые сетки: 3723 вершины; скелет: 76 костей.

Двоичные выходы пересобираются в GitHub Actions. Исходный архив, готовые Blender/GLB и отчёт с их хешами должны прикладываться к тому же GitHub Release, что и игровая сборка. До успешной публикации выходы не считаются переданными пользователю.
