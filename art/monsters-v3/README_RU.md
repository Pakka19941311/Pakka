# Согласованные монстры VARENDOR

Рабочая ветка: `work/character-art-v3`. Модели выбраны владельцем в согласовании R2; отклонённые волк W1 и оборотень L1 не скачивались.

`source-lock.json` содержит авторов, лицензии CC BY 4.0, точные размеры и SHA-256 девяти оригинальных GLB, полученных официальным API Sketchfab. Архив оригиналов восстанавливается из `source-parts/source-*.bin`, сохранённых в Git. Доступ к аккаунту Sketchfab для повторной сборки не требуется. Токен не записывался в исходники, архивы или журналы.

`python scripts/materialize-monsters-v3.py --blender /path/to/blender` проверяет все части и оригиналы, затем запускает реальную обработку Blender. `scripts/build-monsters-v3.py` сохраняет редактируемые `.blend`, отдельные текстуры и игровые GLB. Исходные скульптуры не подменяются примитивами: тяжёлые сетки упрощаются, материалы и нормали переносятся, скелеты подгоняются по модели. Для недостающих действий создаются ходьба, ожидание, удар с контактом, реакция и смерть. Авторские анимации нежити сохраняются там, где применимы.

Оригиналы Хозяина Гнилого Леса имеют CC0 и восстанавливаются отдельным зафиксированным скриптом, см. [forest/README_RU.md](forest/README_RU.md). Wraith помечена NoAI; модель обрабатывается только обычными инструментами Blender и не передаётся генеративным сервисам.

Локальные каталоги `sources`, `editable`, `runtime` — воспроизводимые продукты сборки. GitHub Actions прикладывает фактические Blender-файлы, текстуры, оригинальные GLB и игровые экспорты к Release архивом `Varendor_Monsters_v3.zip`. Механики и балансовые значения описаны в `docs/content-expansion-v3/IMPLEMENTATION_RU.md`.

Игровые версии подготовлены. Проверка `godot-monster-qa.mjs` воспроизводит четыре основных действия всех десяти моделей через контроллер Godot и проверяет высоту стоп наземных моделей. Текущий выпуск подтверждается успешным Actions и опубликованным Release, а не наличием экспорта. Локально применяется Blender 4.2.3, в Actions — зафиксированный Blender 4.5.9.
