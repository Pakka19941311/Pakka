# Varendor — Forgotten Knight, Art v1

Подогнанный персонаж для визуального согласования и дальнейшего подключения к игре: доспехи **The Forgotten Knight** на человеческой основе MakeHuman/MPFB ростом **1,84 м**, меч, три цветовых варианта и **24 именованные анимации**. Модель Paladin не использовалась.

Это пакет художественных ассетов. В текущей игре персонаж ещё не заменён; управление, камера, бой, мир и интерфейс этим блоком не меняются.

## Что открыть

В архиве `Varendor_Forgotten_Knight_Art_v1.zip`:

| Папка | Содержимое |
| --- | --- |
| `Blend` | `Varendor_Forgotten_Knight_Master.blend` — редактируемый персонаж, скелет, материалы и Actions; открыть в Blender 4.2.3 или совместимой версии |
| `GLB` | Готовые экспорты Scarlet, Northwatch и Ashwarden; отдельный `BaseBody.glb` с человеческой основой |
| `Previews` | Изображения и видео для просмотра внешнего вида и движений без установки Blender |
| `Source` | Исходные данные, сценарии сборки и манифесты происхождения/подгонки/анимаций |
| `LICENSES` | Лицензии источников; атрибуция также в `LICENSES.md` |

Для быстрого просмотра откройте картинку и MP4 из `Previews`. В Blender откройте файл из `Blend`, выберите `FK_Humanoid_Rig`, переключите нижнюю область в **Dope Sheet → Action Editor** и выберите нужное действие. Для воспроизведения — пробел. Длина выбранного действия указана в манифесте; диапазон таймлайна нужно выставить под него. Три GLB содержат уже назначенные отдельные палитры.

## Внешний вид и экипировка

**Scarlet / «Алый орден»** сохраняет исходную красную гамму. **Northwatch / «Северная стража»** использует холодные оттенки металла и синий плащ. **Ashwarden / «Пепельный дозор»** — тёмный металл, тёплые детали и коричневый плащ.

Это **три цветовые вариации одного подогнанного комплекта**, а не три разных дизайна доспехов. Сохранены исходные UV и PBR-текстуры; геометрия приспособлена к пропорциям нового тела. Декоративные розы не включены в экипированный комплект.

| Слот | Что отделено |
| --- | --- |
| `head` | Шлем и затемнение смотровой щели |
| `chest` | Корпус, наплечники, элементы ткани/юбки, плащ и его крепления |
| `gloves` | Латные перчатки |
| `boots` | Сапоги и поножи |
| `belt` | Пояс |
| `weapon` | Меч, привязанный к правой кисти |

Слот может состоять из нескольких mesh-объектов. Их связь записана в `fit_manifest.json`; это подготовленное разделение геометрии, а не уже подключённая смена предметов в инвентаре.

Полное тело сохранено скрытым в Blender. В трёх экипированных GLB закрытая бронёй кожа исключена; отдельный `BaseBody.glb` сохраняет основу для будущей сменной экипировки. Для частичного снятия брони потребуется подключить соответствующие видимые участки тела, иначе под снятой частью будет пустота.

## Движения

Скелет: **52 человеческие кости + 4 кости плаща**, всего 56. Анимации Quaternius UAL1/UAL2 Standard перенесены на новый скелет с учётом исходных поз и пропорций; частота ключей — 30 FPS. Исходное поступательное Root Motion отключено, вторичные движения таза сохранены.

| Назначение | Имена Actions |
| --- | --- |
| Стояние | `idle`, `idle_weapon` |
| Бег | `run`, `run_weapon`, `sprint` |
| Основной удар и комбинации | `sword_attack`, `sword_attack_combo`, `sword_attack_heavy` |
| Отдельные удары | `sword_strike_a`, `sword_strike_b`, `sword_strike_c` |
| Возврат после удара | `sword_recovery_a`, `sword_recovery_b` |
| Блок | `block` |
| Каст | `cast_enter`, `cast_loop`, `cast_release`, `cast_exit`, `spell1` |
| Получение урона | `hit`, `hit_head` |
| Прыжок | `jump_start`, `jump_air`, `jump_land` |

`run`/`run_weapon` и `cast_release`/`spell1` используют повторно соответствующие исходные движения для разных состояний. Всего 24 именованных Actions; это не заявление о 24 уникальных исходных записях.

В `run_weapon` отдельно настроено положение правой руки: меч удерживается сбоку и не закрывает забрало при беге. Исходные движения таза, ног, левой руки и остальные Actions сохранены. Эта поправка автоматически применяется `assemble_character.py` через соседний `fix_run_carry.py`.

Удары A/B разделены на удар и восстановление: для полного цикла нужны обе соответствующие фазы. Каст состоит из входа, удержания, выпуска и выхода. Прыжок разделён на отрыв, полёт и приземление. Длительности, зацикливание и исходные названия находятся в `character_manifest.json` и `retarget_metadata.json`.

## Границы этой версии

- Основа тела имеет временный однотонный материал. Финальные кожа, волосы и глаза для вида без шлема не подготовлены.
- Подготовлены движения каста. Новые игровые заклинания, частицы, урон и звук этим пакетом не добавлены.
- При подключении к игре потребуется согласовать существующий адаптер каста/прыжка с отдельными фазами, скорость шага с перемещением и видимость экипировки с состоянием персонажа.
- Момент контакта меча с игровой целью ещё не согласован с событием урона. Фаза `0.5` не считается автоматически правильным моментом удара; замер выноса кисти — диагностический показатель.
- Материальные варианты и разделённые слоты подготовлены как ассеты. Переключение моделей экипировки из инвентаря — следующий блок интеграции.

## Воспроизведение сборки

Сценарии рассчитаны на Blender **4.2.3**, без установки MPFB-аддона. Команды запускаются из корня распакованного пакета. `blender` должен быть доступен в PATH, иначе используйте полный путь к `blender.exe`. Все результаты ниже создаются отдельно в папке `Rebuild`.

Входы для повторной сборки: оригинал `Source/Armor/knight.blend`; человеческий builder и данные в `Source/Human`; исходные UAL1/UAL2, готовые Actions и настройка меча в `Source/Animations`. Сценарии находятся в `Source/Scripts`.

1. Повторный перенос анимаций из оригинальных библиотек на человеческую основу. Параметр `--no-render` пропускает повторный рендер технических ракурсов; сам перенос выполняется полностью.

```bash
blender --background --threads 2 --disable-autoexec --python Source/Scripts/retarget_actions.py -- --human-builder "Source/Human/build_human.py" --ual1 "Source/Animations/UAL1_Standard.glb" --ual2 "Source/Animations/UAL2_Standard.glb" --output "Rebuild/Animations" --no-render
```

2. Подгонка доспехов:

```bash
blender --background --threads 2 --disable-autoexec --python Source/Scripts/build_fitted.py -- --source "Source/Armor/knight.blend" --body-builder "Source/Human/build_human.py" --output "Rebuild/Fitted"
```

3. Сборка с Actions и настройкой крепления меча:

```bash
blender --background --threads 2 --disable-autoexec --python Source/Scripts/assemble_character.py -- --base "Rebuild/Fitted/Forgotten_Knight_Fitted_Base.blend" --actions "Rebuild/Animations/retargeted_actions.blend" --socket "Source/Animations/sword_socket_evidence.json" --output "Rebuild/Assembled"
```

Первый шаг можно пропустить и в третьем использовать готовый `Source/Animations/retargeted_actions.blend`.

4. Экспорт трёх вариантов и отдельного тела:

```bash
blender --background --threads 2 --disable-autoexec --python Source/Scripts/export_assets.py -- --master "Rebuild/Assembled/Varendor_Forgotten_Knight_Master.blend" --output "Rebuild/GLB"
```

`export_assets.py` использует лежащий рядом `assemble_character.py`. Итоговые файлы и проверки структуры фиксируются в `export_manifest.json`. Параметр `--preflight` проверяет входную сцену без экспорта; для выбора палитры есть `--variants scarlet northwatch ashwarden`.

Человеческую основу отдельно можно пересобрать так:

```bash
blender --background --threads 2 --disable-autoexec --python Source/Scripts/build_human.py -- --data "Source/Human/prepared/athletic_male_hm08.json" --out "Rebuild/Human/Varendor_Human_Male"
```

`create_human(collection=..., height=...)` сохраняет прежний интерфейс; дополнительный именованный аргумент `data` позволяет указать JSON в другой папке. Если он не задан, builder ищет `prepared/athletic_male_hm08.json` рядом с собой.

В Blender единицы — метры, вверх +Z, вперёд −Y; в GLB — метры, вверх +Y, визуальное направление вперёд +Z. Студийное поднятие персонажа на 2 см удаляется при экспорте.

Источники и обязательная атрибуция брони: см. `LICENSES.md` и `source_provenance.json`.
