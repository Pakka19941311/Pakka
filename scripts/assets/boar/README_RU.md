# Воспроизводимая адаптация кабана

Blender 4.2.3. Источник и SHA-256 указаны в source.json. Исходный архив остаётся в intake. Скрипты отключают исполнение исходных Text blocks и выбирают только Boar + Boar skeleton, исключая всадников. Никакие модели не загружаются автоматически.

Последовательность: prepare_source.py → adapt_anatomy.py → normalize_actor.py → measure_stride.py. Первые два шага создают промежуточные prepared/anatomy файлы внутри `<cache>/MOB-04-boar-enemies`; последние создают отдельный GLB и отчёты в новых каталогах. Общая форма команды:

```text
blender --background --factory-startup --disable-autoexec --python scripts/assets/boar/<script>.py -- --intake <cache> --output <new-model-dir> --reports <new-report-dir> --repo <repo>
```

Выход normalize_actor — V3BoarCandidate.glb с шестью клипами, candidate.blend, отчёты и два Blender кадра. measure_stride читает этот candidate.blend и измеряет опорные маркеры по 241 фазе. Не запускайте воспроизведение поверх опубликованного кандидата для одной лишь проверки. Версия Blender/GLTF может менять байты; сравнивайте состав, геометрию, размеры и анимационные данные.

Шерсть и клыки основаны на исходном арте. Авторские изменения: закрытая кожа вместо плоских щёчных лоскутов, короткая щетина, объёмные уши, глаза, восемь половинок копыт и hit-отдача. Подробные provenance и изменения длительностей находятся в ADAPTATION.json. Трот не переименовывается в отдельный исходный галоп.
