# Pakka — Browser 3D Dark-Fantasy RPG

Основной репозиторий браузерной 3D RPG.

Текущее состояние: **Varendor v0.4 — Phase 1 завершён**. Игровой клиент находится в корне репозитория, собран на Babylon.js, TypeScript и Vite. Стабильная v0.3 сохранена отдельной контрольной веткой; Phase 2 ещё не начинался.

## Роли

Пользователь — владелец продукта, геймдиректор и тестировщик. Он принимает решения по игровому результату, визуалу, балансу и ощущениям от игры.

ChatGPT/Work — Lead Game Developer, Game Systems Designer, Technical Architect, 3D/Frontend Developer и QA. Технические решения принимаются самостоятельно без перекладывания программирования на пользователя.

## Главный принцип

Сначала создаётся полноценный локальный браузерный игровой клиент, но архитектура сразу предусматривает последующее подключение backend, аккаунтов, БД и мультиплеера без переписывания игрового ядра.

Нельзя выдавать технические заглушки за готовый игровой результат. После каждого существенного этапа требуется сборка, runtime-проверка и регрессионный тест основных механик.
