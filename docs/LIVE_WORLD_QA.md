# Блок A — мир без общей паузы

База: `999e90a53511af40ddff5aaca5a7d3ed1d1fc65d`, ветка `work/v06-commercial-rebuild`.
Статус исходников: кандидат A. Windows Release создаётся только после успешных gates этого же SHA; опубликованная сборка ожидает теста владельца. Следующий блок до принятия A запрещён.

Изменено:
- Окна сумки, характеристик, карты, навыков, настроек, NPC, подтверждения и смерть не останавливают симуляцию. Tab переключает текущую сумку, Esc закрывает верхний слой.
- После смерти герой не двигается, не использует предметы/навыки. Тело в прыжке опускается на опору. Выпущенный ранее навык не лечит погибшего или героя следующей жизни.
- Монстры теряют погибшую цель, возвращаются и продолжают патруль. Смерть не останавливает респавны мира и таймеры.
- Сохранение погибшего загружается с экраном возрождения без второго штрафа XP. Нажатие «Возродиться» возвращает в Гринфолл.
- Подтверждения одноразовые; смерть/закрытие инвалидируют старые callbacks. Затемнение верхнего подтверждения блокирует клик по основному окну.
- Фокус текста и открытие/закрытие окон сбрасывают удержанный ручной ввод. Автоповтор старой клавиши не возобновляет движение после сброса. Клавиатура подтверждения не отдаёт новые команды движения/прыжка.
- Предметные действия повторно находят вещь по UID; кузница повторно проверяет вещь, уровень и запас перед единственным расходом.

Границы: новая компоновка сумки и её hover/double-click, доводка боя E и четыре свитка с балансом V2 описаны в TZ_V2_RU.md и относятся к следующим блокам. В A действующая математика заточки не меняется.

Проверки выпуска:
1. Unit tests, TypeScript, production build, asset verifier и загрузка реальных ресурсов.
2. Chromium WebGL на production: реальная сцена, отсутствие QA-фикстур, игровые окна, Tab repeat, cooldown, чат, движение и верхнее подтверждение.
3. Отдельный QA build того же исходного SHA: реальная атака монстра при открытой сумке, смерть, запрет предметных действий/навыка с достаточным MP, патрули и респавн монстра на настоящих тиках, ненулевой штраф XP, reload, respawn, устаревшее подтверждение, смерть в прыжке.
4. Windows PowerShell launcher: HTTP HTML, MIME/содержимое JS с query-параметром, полная передача GLB.
5. Production ZIP, целостность, размер, SHA256; BUILD_COMMIT.txt и JSON evidence включены в пакет.

Браузерные JSON-отчёты содержат фактический SHA, версию Chromium, выполненные checks, ошибки и passed. Отдельный QA evidence ZIP содержит снимки. CI использует программный WebGL: начальный кадр High, проверки взаимодействий Low/50%; это не прогноз FPS на игровом ПК и не скрытое снижение качества пользовательской сборки.

Прежняя недоступность локального браузерного сервера не считается проверкой игры; текущий выпуск проверяется в GitHub Actions. Если gate завершается ошибкой, Release не создаётся. Ссылка на успешный запуск добавляется в отчёт автоматически только при упаковке.

Для владельца: пройти город/ворота, открыть сумку и настройки под атакой, проверить смерть, просмотр сумки и возрождение. Передать замечания. После выдачи сборки — СТОП до принятия A.
