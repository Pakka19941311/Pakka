# Технические источники и лицензии

Проверены 10.09.2026 при подготовке ТЗ. Это первичные источники, а не перечень уже скачанных или интегрированных ассетов. Для выполнения использовать документацию фактической версии проекта. Страницы `stable` могут изменяться; их открытие не является основанием обновлять движок.

## S01 — Godot: Available 3D formats

`https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html`

Основание: glTF 2.0 рекомендован для обмена; прямой импорт `.blend` вызывает Blender для преобразования в glTF и требует соответствующей среды. Не считать все процедурные материалы Blender автоматически совместимыми с конечным рендером.

## S02 — Godot: Optimization using MultiMeshes

`https://docs.godotengine.org/en/stable/tutorials/performance/using_multimesh.html`

Основание: отдельные экземпляры одного MultiMesh не отсекаются независимо по фрустуму; пространственное разделение массовой растительности позволяет избежать одной глобальной области видимости. Страница содержит оговорку об актуализации под версию движка; проверить поведение в версии проекта.

## S03 — Godot: Visibility ranges (HLOD)

`https://docs.godotengine.org/en/stable/tutorials/3d/visibility_ranges.html`

Основание: дальние группы можно заменять более простой геометрией через диапазоны видимости. Художественный силуэт и стабильность перехода проверяются отдельно.

## S04 — Godot: Background loading

`https://docs.godotengine.org/en/stable/tutorials/io/background_loading.html`

Основание: `load_threaded_request` запускает фоновую загрузку; `load_threaded_get` может заблокировать поток, если ресурс не готов. До получения результата проверять статус.

## S05 — Godot: Thread-safe APIs

`https://docs.godotengine.org/en/stable/tutorials/performance/thread_safe_apis.html`

Основание: работа с активным деревом сцены не является потокобезопасной. Разделять фоновые вычисления и безопасное подключение к сцене; не изменять один ресурс одновременно из нескольких потоков.

## S06 — Godot: Optimizing Navigation Performance

`https://docs.godotengine.org/en/stable/tutorials/navigation/navigation_optimizing_performance.html`

Основание: упрощённая исходная геометрия, уменьшение избыточной детализации навигации, отказ от ненужного повторного запроса пути каждый кадр и распределение запросов агентов по времени.

## S07 — Godot: Volumetric fog and fog volumes

`https://docs.godotengine.org/en/stable/tutorials/3d/volumetric_fog.html`

Основание: объёмный туман относится к Forward+; для других рендереров требуется другое решение. Проверять ограничения конкретного целевого профиля.

## S08 — Terrain3D: официальный репозиторий

`https://github.com/TokisanGames/Terrain3D`

Основание: редактируемый ландшафт для Godot, работа с отверстиями, текстурами и растительностью; лицензия MIT. Это кандидат после проверки совместимости, а не обязательная замена текущего инструмента.

## S09 — Poly Haven: лицензия ассетов

`https://polyhaven.com/license`

Ассеты заявлены под CC0, включая коммерческое использование. Лицензия ассетов не означает автоматического разрешения на любой другой контент сайта или обход условий сервиса.

## S10 — ambientCG: лицензия

`https://docs.ambientcg.com/license/`

Ассеты заявлены под CC0 1.0 Universal; разрешены изменение и коммерческое применение. Для конкретного принятого файла сохранить происхождение и подтверждение условий.

## S11 — Kenney: условия использования игровых ассетов

`https://kenney.nl/support`

Автор указывает CC0 для ассетов на соответствующих страницах, с возможностью коммерческого применения. Проверять страницу и включённый файл лицензии конкретного набора; не распространять это на логотипы и иной контент.

## S12 — Quaternius: FAQ и лицензия моделей

`https://quaternius.com/faq.html`

Автор указывает CC0 для моделей и возможность коммерческого использования и модификации. Проверять конкретный набор; подходящий правовой статус не означает соответствия реалистичному стилю Varendor.
