# B — HUD и быстрые действия

База: принятый C 608c10eb. Рабочая ветка work/v06-commercial-rebuild; main не меняется.

Изменены: единая раскладка дока, HP/MP/XP, миникарта/цель/эффекты, журнал, 32 настраиваемых быстрых слота, общий запас расходников и двойной клик одной попытки использования. Сохранение назначений, свободные Shift-сочетания, отказ конфликтующих клавиш. Компактный инвентарь учитывает фактическую высоту дока. Старые Q/E не сбрасываются. Заточка V2 не входит в B.

Обязательные gates текущего SHA:
- Unit: нормализация старого/повреждённого quickbar, конфликты клавиш, browser modifiers; принятые gameplay tests.
- Build: tsc, assets, production bundle без mutating fixtures, реальный lifecycle smoke.
- scripts/hud-regression.mjs: production и отдельный QA runtime в Chromium software WebGL; реальные кнопки/двойные клики/клавиши, UI 80/100/125%, 1280×720 / 1366×768 / 1920×1080 / 2560×1440, 2/4 ряда, инвентарь, сохранение/перезагрузка, последний/пополненный stack, эффекты и смерть.
- Регрессии C/E/A на этом же SHA. Windows PowerShell: HTML, JS MIME, полный GLB.
- Release только после passed=true во всех восьми JSON с совпадающим SHA и errors=[].

Фактические результаты и SHA прилагаются к ZIP отдельными машинными reports. Software WebGL не подтверждает FPS на пользовательском GPU.

Пользовательский тест: бой с открытой сумкой, чтение ресурсов/цели, Q/E и последний расходник, 4 ряда → настройка свободной ячейки → перезагрузка, изменение масштаба. После выдачи ZIP статус awaiting_user_test, остановка до принятия B.
