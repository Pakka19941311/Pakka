## Исправленные причины непроходимости

Старый `starterLocation` распознавал только прежний городской контур. Убийства вне него считались через slot L02, но осмотр, отмена движения и обход получали другую локацию. Теперь `FinalWorld.populationLocation` использует единый административный P2-контур; защита safe остаётся прежней. Тот же `P2_LOCATION_OVERRIDES` предназначен для подписи «Гринфолл» на нативной карте.

Первый геометрический прогон обхода обнаружил, что ближайшая плотная группа кабанов не давала непрерывного четверть-круга вне восприятия гончих. Для одной обычной внешней пары из существующих45 кабанов создано свободное место; дома гончих отнесены от её центра на27м. Этой паре не добавлены иммунитет, новый тип или safe-зона. После изменения маршрут пройден серверным наблюдателем без ручной подстановки этапов.

Композиционные тесты проверяют150 сохранённых UID/уровней,12 пар гончих и одиночную25-ю,19м между независимыми зонами восприятия,22 живые кабаньи группы,18 первых подходов, физическую связность и отсутствие длинных рядов слабых существ. Relayout-тест переносит только idle-тело и сохраняет HP, эффекты, смерть, generation и таймеры; активный бой получает только новый дом для возврата.

## Что не подтверждено этим прогоном

Это серверная проверка конкретных маршрутов рыцарем при фиксированном RNG. Она не заменяет ручную навигацию, нативный LMB, качество анимации, статистику случайных промахов, многократное лечение, QUEST102, рост1→7 или проверку каждого класса на всей цепочке. Godot во время этой правки не запускался из-за параллельного расследования access violation; generated/game.json не менялся. Первичная запись25+5 боёв находится в `P2_COMBAT_RESULTS.json` и относится к прежней композиции; новые маршруты имеют отдельный digest и не смешиваются с той сдачей.
