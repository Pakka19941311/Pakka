# P2: локальное сравнение поправок содержания рыцаря2

**ПРОЕКТ: production-параметры не изменены.** Минимальный результативный рычаг в проверенном наборе — дополнительная пауза **1,0с между началами атак** только у MOB-01 «Теневой слизень» и MOB-03 «Полевая крыса» уровней1–2. Она меняет `attackInterval`: слизень2,3→3,3с, крыса1,9→2,9с. Первое нападение, windup0,55/0,45с, recovery0,7с, сам attack clip, скорость перемещения, HP/ATK/DEF, минимум1HP, точность, опыт, таблицы добычи и цены остаются прежними. Это предложение для отдельного принятия, а не уже установленный баланс.

## Откуда взялась проблема

Фактическая полная серия из `P2_PLUS3_ECONOMY.json` — рыцарь2 со starter+3, пять слизней и пять крыс уровня2, мир1151: потери **45HP (24+21)**, монеты149, действительная продажа75, gross224. После возвращения потребовались две реальные бутылки:37+8HP, затраты110, доля49,11%. Начальный запас из трёх зелий за165 отделён от содержания повторяемого маршрута. Дополнительные HP героя не сокращают цену восстановления потерянного здоровья.

DEF рыцаря+3 равен46. При нынешнем физическом вычете0,2×DEF=9,2 атаки обоих видов уже достигают нижнего предела1HP. В изолированной контрольной серии все52 попадания дали ровно по1HP. Поэтому ATK−1 у этих видов сохранил **52HP**, те же попадания и TTK: снижение доработано настоящим прогоном, а не выбрано по предположению. Добавление DEF также не снимает этот предел и затрагивает экипировку шире нужного.

В каждом бою отдельный начальный fixture рыцаря2+3 и изолированный противник. Фиксированное семя каждого UID одинаково между кандидатами. Это **синтетическое сравнение**, без переходов/продажи/покупок и без остальных1141 сущностей. Его baseline52HP отличается от полной серии45HP; числа нельзя выдавать за повтор полного маршрута.

Потенциальный DPS оружия и HP врагов не изменяются.

## Альтернативы и рекомендуемое ограничение

Сохранить прежний ритм и обе бутылки при фактическом gross224 можно, только подняв gross минимум до**275**:110/0,4. Это+51 за10 врагов, в среднем+5,1 на убийство. Если менять только монеты, прежние149 должны стать200 (**+34,2%**); если только фактическую цену материалов,75→126 (**+68%**). Эти вычисления не обещают тот же случайный дроп на другой серии. Такая прибавка масштабирует доход всех фермеров/крафт и шире локального провала; не рекомендуется без отдельного экономического основания. Фиксированные цены55/110 и лечение37/70 сохранены. Бесплатная HP-регенерация, дробный урон ниже1 и общий бонус экипировке не предлагаются.

Рекомендуемый кандидат — **единственный дополнительный cooldown+1с** для двух названных видов **только уровней1–2**, без проверки класса игрока. Уровень3+, волки, кабаны, жуки, остальные43 вида и большие/мини-боссы остаются вне этой поправки. Кандидат уровней1 и2 ограничен этой областью данных, но бои фактически измерены только на уровне2; уровень1 при реализации требует короткого связанного smoke. Прежние четыре успешные +3 серии других классов сохраняются: их целевые уровни3/5/7–9 не входят в предлагаемый диапазон.

Следующий шаг после принятия: отдельный версионированный P2 override, затем один полноценный affected-route рыцаря с1151, актуальный level1 smoke и короткий нативный осмотр паузы. Не повторять остальные пятьдесят боёв без нового риска. Полный1–90, книги с процентным уроном и бой15 против голема/пита остаются открытыми.

## Воспроизведение

`node --experimental-strip-types scripts/world_expansion_v3/p2-upkeep-candidates.mjs` — изолированная таблица; `--sensitivity` — дополнительные наборы; `--continuous` — реальные команды шести непрерывных серий в изолированной популяции. Все изменения профилей живут только в памяти этого процесса и восстанавливаются в `finally`, включая аварийное завершение fixture. Источники production захешированы до/после; изменений во время прогонов не было.

Данные: `P2_UPKEEP_CANDIDATES.json`, `P2_UPKEEP_SENSITIVITY.json`, `P2_UPKEEP_CONTINUOUS.json`. `tests/p2-upkeep-candidates.test.mjs` проверяет границы временной поправки, восстановление cache после исключения, фактический minimum-hit, полные цели, покадровые попадания, непрерывность ресурсов и реальные денежные/лечебные операции. Воспроизводимый вход `runPlus3Case` получил необязательную фабрику драйвера для этой изоляции; стандартный прогон по умолчанию продолжает использовать1151.
