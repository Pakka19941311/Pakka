# Сокращение лишних копий снимков P2

Статус: реализация проверена изолированным native QA — **28/28 PASS**, exit 0 за 2,297 с. Это изменение стоимости обработки данных; частоты получения, представления, анимации и физики не меняются. Дальность видимости, движение героя и популяция сохраняются. Отдельного замера FPS после этой правки ещё нет.

## Изменение

1. `snapshot_timeline.gd` больше не строит глубокие копии промежуточных состояний и событий для `transitions`: в действующем клиенте и QA нет читателя этого массива. Ключ результата оставлен пустым; конечный `snapshot` и упорядоченные `events` возвращаются прежним способом.
2. В `ingest` события отделяются от уже глубоко скопированного `owned` без повторного `duplicate(true)`. Замена `owned.events` на пустой массив не уничтожает сохранённую ссылку на его прежний массив. Исходный сетевой словарь остаётся изолирован.
3. SSE-декодер продвигает `consumed` внутри одного буфера и единожды отрезает обработанный префикс после цикла. Раньше остаток буфера копировался после каждого полного пакета. Каждый полный JSON по-прежнему разбирается; объединение и сортировка событий, ограничение 2048 событий, выбор latest по revision/time, один вызов accept и обработка ошибки сохранены. Неполный пакет остаётся байтами, включая незавершённый UTF-8 и одиночный завершающий LF.

Глубокие копии `current = _snapshots[0].duplicate(true)` и возвращаемого `result.snapshot` сохранены. Они нужны, поскольку применение событий меняет HP/смерть/цель внутри current, а world обновляет время своего снимка. Удаление этих копий нарушило бы изоляцию исторических состояний и вызывающего кода.

## Проверка

Отдельный `p2_snapshot_copy_acceptance.gd` запускает прежние `snapshot_timeline_qa.gd` и `network_qa.gd`, без действующего мира и renderer. Прежняя матрица включает порядок attack/release/hit/death/loot, момент изменения HP, повторные события, generation, смерть/respawn, same-tick revision, паузу сети и восстановление после разрыва; сетевые проверки включают побайтную кириллицу, burst из 20 пакетов с 20 событиями и устаревшие ответы профилей/квитанций.

Добавлены только два отсутствовавших случая, связанные с изменённой границей владения:

- Изменение входного события и вложенного словаря после ingest не меняет ожидающее событие; ingest не добавляет поля в исходный объект.
- После полного пакета неполный UTF-8 хвост переживает compaction и два следующих вызова декодера, в том числе разделитель LF/LF, разрезанный между вызовами. Пакеты не принимаются раньше времени и не дублируются.

Исходный patch и нормализованные SHA сохранены до применения вне исходников проекта: `varendor-world-gameplay/work/p2-snapshot-copy-patch/`. Shared runtime изменён после явного SOURCE CLEAR ведущего агента и затем заморожен на время соседнего line QA. Native-запуск разрешён только через `scripts/godot_run_checked.py`, с новым каталогом отчёта.
