# P2: отдельные движущиеся стражник и житель

Два кандидата для последующего подключения на существующие ID и маршруты. Этот блок не редактирует live-популяцию, городскую геометрию, услуги, сервер, `generated/game.json` и исходные `P2_guard.glb` / `P2_resident.glb`.

## Что изменено

Стражник: спокойная стойка, расслабленные кисти, простой открытый шлем без рогов и гребня, короткий меч в новых кожаных ножнах на двух ремнях. Использован уже разрешённый Forgotten Knight с обязательной отдельной атрибуцией CC BY 4.0; тело и одежда MPFB остаются CC0. Герой сохраняет собственный силуэт. Меч пока находится в ножнах: обнажение оружия и боевые клипы в эту городскую пробу не входят.

Житель: стойка, неглубокий размеренный шаг, разговорный жест; низ рясы расширен по глубине и поднят до щиколоток, веса подола плавно переходят к тазу и бёдрам. Скрытая под рясой высокая часть сапог удалена. Видимые стопы и носки сохранены; одежда подгонялась по реальным фазам, включая выявленное в Godot прорезание сзади/сбоку при поднятой ноге.

Все движения заново созданы в Blender на реальном 53-костном `game_engine` риге. Копирование UAL-движений не заявляется. Исправлен обнаруженный дефект IK: потеря масштаба импортированного рига при задании матриц приводила к погружению сапог на 3 см после воспроизведения ключей. Расчёт использует фактические расстояния между суставами и сохраняет масштаб матриц, без растяжения костей.

| Профиль | Основа тела | Скорость | Цикл шага | Длина полного цикла |
|---|---:|---:|---:|---:|
| guard | 1,80 м | 1,00 м/с | 1,30 с | 1,30 м |
| resident | 1,74 м | 0,90 м/с | 1,40 с | 1,26 м |

Оба GLB содержат `idle` 4 с, `walk`, `talk` 3,2 с и два поворота на 90° по 1,2 с. Idle, walk и talk замкнуты; позы запечены с частотой 30 Гц. В GLB нет поступательного движения игрового корня: оно принадлежит движению NPC, а адаптер задаёт фазу по фактически пройденным метрам. Поворот использует переступание двумя ногами и согласованную кривую yaw корпуса.

## API для отдельного подключения

`res://world-expansion-v3/city/motion/npc_motion_adapter.gd`:

- `create_actor(world, persistent_id, "guard" | "resident")` создаёт новый визуальный узел через действующий `World.make_actor`. Вызывать в точке первичного создания актёра, сохраняя прежний ID. Это не функция замены уже существующего узла.
- `advance_actor(actor, state, dt, travelled_m)` задаёт фазу выбранного клипа. Для walk передавать **реальное** расстояние за кадр после collision/остановки; не умножать фазу на абстрактную скорость при стоящем NPC.
- `pose_at(actor, state, normalized_phase)` предназначен для точной выборки и согласованного внешнего контроллера. Выбранный AnimationPlayer уже работает в manual-режиме через действующий bind.
- `turn_yaw(progress, left)` возвращает плавный поворот на ±90°. Эти клипы калиброваны именно для 90°; произвольные углы и переходы на существующих маршрутах требуют отдельной интеграционной проверки.

Новый адаптер должен стать единственным владельцем позы этих двух актёров; общий animation controller нельзя продолжать обновлять для тех же узлов. Существующие коллизии, nameplate, разговор, услуги и маршруты остаются обязанностью live-слоя. Регистрация профиля опирается на рост тела, поэтому шлем и ножны не меняют размер NPC и положение его корня.

## Проверка и границы результата

`npc_motion_sample.tscn` — отдельная сцена без сервера: стойка → три цикла перемещения → остановка → поворот → разговор. Существующий городской мир не загружается. Проверены сами GLB и их реальные Skeleton3D, а не только декларативные значения скорости.

- Blender: замыкание всех костей idle/walk/talk, сохранение масштаба костей, постановка стоп с добавлением реального поступательного движения. Максимальное расхождение опорной стопы между кадрами менее 0,001 мм; ошибки замыкания позиции/угла равны нулю в сохранённых отчётах.
- Godot: 53 кости, пять клипов, фактическая скорость корпуса, опорные стопы на шаге и повороте. Порог 2 мм/кадр для шага и 3 мм/кадр для поворота. Числа, кадры и результат последнего прогона находятся в `npc-motion-evidence/NPC_MOTION_QA.json`; тест сверяет точный SHA256 GLB с Blender evidence.
- Просмотрены стойки спереди/сбоку/в три четверти, восемь фаз шага, разговор и переступание в Blender, затем соответствующие кадры Godot. Это кандидат для игрового подключения, а не пользовательская приёмка окончательного качества всех NPC.
- Финальный повторный прогон: **12/12**, exit 0 за **20,125 с**, `timed_out=false`, `crash_detected=false`; критерий закреплён в тесте по `native-result.json`. Предыдущий прогон записал 12/12 проверок и вернул exit 0, но пересёк лимит 35 с у запускателя: он сохранён как `native-time-limit-result.json` и не считается успешным процессом. Повтор на неизменённых GLB получил лимит 50 с. Известные сообщения окружения о недоступном `user://` shader cache и root certificate сохранены в журнале и не объявляются исправленными данным блоком.
- Четыре проверки Node по skin/геометрии/анимационным каналам/SHA/реальному runtime и компиляция двух Python-скриптов пройдены. Контакт стоп ограничен рассмотренными прямыми шагами и поворотом на 90°; отдельной live-проверки произвольного движения по городу это не заменяет.

Открыто для следующего live-подключения: переходы клипов на действительных остановках/углах маршрута, наклоны земли и лестницы, проверка встречных NPC, клика/разговора при движении. Полной системы динамической ткани, оружейной боевой анимации и лицевого lip-sync в этом блоке нет. У стражника сохранены исходные большие карты материалов; оптимизация атласов и LOD требует отдельного визуального сравнения.

## Воспроизведение

Нужен Blender 4.2.3; внешний аддон не требуется. Из корня репозитория:

```powershell
python scripts/assets/city/run_npc_motion.py --blender C:/path/to/blender.exe --role guard --reports work/npc-reproduce/guard --output godot-pc/world-expansion-v3/city/motion/assets
python scripts/assets/city/run_npc_motion.py --blender C:/path/to/blender.exe --role resident --reports work/npc-reproduce/resident --output godot-pc/world-expansion-v3/city/motion/assets
```

Каждый свежий каталог получает редактируемый `.blend`, PNG фаз, JSON замеров и результат `blender_run_checked.py`. Скрипт берёт уже имеющиеся разрешённые GLB из репозитория, не скачивает модели и не запускает вложенный сторонний код.

Godot запускать **только** через `scripts/godot_run_checked.py`, после согласования очереди engine. Сначала `--headless --editor --import`, затем сцену `res://world-expansion-v3/city/motion/npc_motion_sample.tscn` с `-- --npc-output=ABSOLUTE_FRESH_OUTPUT`. Каталог вывода самого checked launcher можно использовать для PNG/JSON сцены. Лимит сцены 14 с, процесса — 50 с с учётом загрузки/завершения. Пример формы команды:

```powershell
python scripts/godot_run_checked.py --exe C:/path/to/Godot_console.exe --project godot-pc --output work/npc-native-new --timeout 50 -- res://world-expansion-v3/city/motion/npc_motion_sample.tscn -- --npc-output=C:/absolute/repo/work/npc-native-new
node --experimental-strip-types --test tests/p2-npc-motion.test.mjs
```

Лицензии: `godot-pc/world-expansion-v3/city/motion/CREDITS.md`. Точечные проверки читают структуру skin/animations/позиции GLB, замыкание всех каналов и соответствие доказательств текущим бинарным файлам.
