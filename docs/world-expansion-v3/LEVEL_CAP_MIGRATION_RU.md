# Ограничение уровня 90 и старые сохранения

Сервер применяет ограничение до расчёта характеристик при загрузке SQLite и при private beta import. Старые уровень и опыт сохраняются в `legacyProgression`; предметы и золото не затрагиваются, здоровье не восстанавливается, смерть не отменяется. Опыт на максимальном уровне ограничен значением `xpNeeded(90)-1`. Повторная загрузка не переписывает исходную запись и не начисляет бонусы снова. Уровни ниже 90 не меняются.

При private import исходный документ остаётся в существующей атомарной резервной записи WorldStore. Проверки проводились только на временных SQLite, без открытия пользовательского сохранения.

Проверки: 9 целевых тестов, включая настоящий SQLite restart для всех пяти классов, повтор импорта, сохранение вещей, HP/MP, отказ повреждённого импорта и отказ записи. TypeScript без ошибок. Этот блок не заменяет обязательную проверку переноса сохранения в итоговом ZIP.
