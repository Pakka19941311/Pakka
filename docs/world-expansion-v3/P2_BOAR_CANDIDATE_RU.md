# Новый кабан MOB-04: отдельный кандидат

Выбран [Boar enemies](https://opengameart.org/content/boar-enemies): Danimal, исходная модель Myname, сохранён дополнительный credit Clint Bellanger. Используется только кабан без всадника и доспехов. Архив boar.7z получен с первичного сайта; SHA-256 `5183039c6097e860e6d5b611ca79c70ea135d91602ca4e213aede7442b9a8364`. Лицензия CC BY-SA 4.0: полные условия и атрибуция находятся рядом с GLB. Для выпуска подготовлен P2_BOAR_ART_PACK.json с отдельными файлами за пределами PCK; независимый игровой код не меняет лицензию.

Удалена высокая плоская грива. Добавлены короткие послойные пучки щетины, объёмные уши, небольшие глаза и восемь половинок копыт. Они имеют веса на существующих костях, не приклеены к корневому объекту. Закрыты исходные щёчные лоскуты с сохранением граничных UV; нормализованы skin weights. Исходная меховая текстура 512×512 и общая простота ног остаются ограничениями кандидата. Чёрный тон обратной стороны ближнего уха следует оценить на игровом масштабе.

Рост 0,8 м; ширина около0,425 м; длина около1,35 м. Предложенный радиус 0,48 м сохраняет прежний контракт, фактический серверный bodyRadius имеет приоритет. Направление приведено к принятому адаптеру, проверено для четырёх server yaw. Базовая точка модели лежит на уровне опоры.

Сохранены исходные idle, trot, attack, death. Run использует исходный темп NLA 0,45: цикл 0,75 сек; walk — замедленная версия того же движения 1,25 сек. Отдельный исходный галоп не заявлен. Idle растянут до 3 сек, атака до 1 сек; hit 0,333 сек создан локально на spine/head. Исходный стык правых копыт около 7 см исправлен плавным замыканием каналов по циклу, с явным авторским provenance. Пол и поза смерти корректируются по реальной skinned геометрии.

По 241 фазе опорных маркеров walk даёт 0,708858 м/с, run 1,181192 м/с. Скорость 1,6 м/с требует playback≈1,355 при пределе 1,65. Это оценка по медиане, а не обещание нулевого скольжения: разброс скоростей отдельных копыт сохранён в BOAR_STRIDE_SAMPLES.json. Прежняя скорость или новая скорость выше 1,949 м/с этому профилю не подходят без дополнительной работы с циклом.

Изолированная native сцена создаёт актёра через VarendorWorld.make_actor и общий P2 adapter; на момент первого прогона профиль подменялся только в памяти проверочного процесса; после принятия сцена читает canonical профиль. Пройдено 35/35 условий: шесть меняющихся клипов, ориентация, picking, радиус, hit point, один серверный hit, попадание по заданному impactAt, ограничение частоты шага, остановка, пол в idle/death, удержание и удаление трупа. Дополнительно показано перемещение 1,6 м/с по неподвижной разметке пола. Это не серверная погоня по рельефу.

Запуски выполнены scripts/godot_run_checked.py. Exit 0; logfile создан заранее; аварий и ошибок освобождения ресурсов нет. Ошибки окружения shader-cache/user и certificate-store сохранены в полных логах и не скрываются. Первый набор кадров содержит неправильную кодировку разделителей в QA заголовке; сами модель, профиль, проверки и текст имени корректны. Исходник QA после этого исправлен на чтение UTF-8.

Кандидат находится в actors/alternatives/boar. Интегратор принял его как рабочую P2 замену после просмотра новой анатомии и native run. Canonical profiles.json обновлён только для MOB-04; live world и server этот блок не меняет. Следующие gates — финальная детализация и настоящая погоня на сервере. Воспроизводимые Blender-скрипты находятся в scripts/assets/boar; отдельный GLB должен совпасть по данным и SHA при неизменной версии инструментов.

Интеграционный прогон настоящего клиента и сервера подтвердил для нового кабана 16 из 16 условий: выбор ЛКМ, прежний аккорд автоатаки, бой от полного здоровья до смерти, добыча, часы действия и остановка. Проверен [отчёт интегратора](live-p2-evidence/battles-checks.json). Бой начинался примерно в 3 м от цели; длинный маршрут преследования этим результатом не закрывается.
