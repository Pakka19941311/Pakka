# Состав текущего игрового пакета P2

12 сентября 2026. Проверены генерация export filters, выбор отдельных SA-ассетов и копирование атрибуции. Godot, prepare, экспорт EXE и скачивание архивов в этом блоке не запускались. Проверка готового PCK остаётся за финальной сборкой.

## Исключение непринятых моделей

`scripts/godot-pc-data.mjs` не записывает export presets. Фактический генератор `scripts/world_final/prepare_gameplay.mjs` теперь использует `gameplay-export-policy.mjs`. Существующие настройки всех пресетов сохраняются; к `exclude_filter` добавляются:

- `world-expansion-v3/actors/cohort-06-10/*`: вся неактивная когорта, включая модели, изображения, профили и возможные кандидатские QA-сцены.
- `world-expansion-v3/actors/alternatives/roach/*`: прежний четырёхногий образец и его QA.
- `world-expansion-v3/actors/models/V3StarterBoar*` и `V3StarterBeetle*`: отвергнутые ранние прототипы и их текстуры.

Соответствующие JSON также исключаются из явного `include_filter`. Исходные файлы остаются в репозитории. Повышение следующей когорты до игрового статуса потребует явного изменения политики, профилей и приёмки; одно наличие GLB больше не означает включение в этот выпуск.

Проверка всех сохраняемых `.gd`, `.tscn`, `.tres` и `project.godot` не нашла буквальных `res://` ссылок на исключаемые ресурсы. Единственная ссылка на QA четырёхногого Roach находится внутри исключаемого каталога. Canonical MOB-01…05, `stage_acceptance`, `p2_pursuit_acceptance`, `p2_nature_acceptance`, NPC motion и природа не исключаются. Это статическая проверка зависимостей, не утверждение о native-прохождении будущего PCK.

## Атрибуция рядом с PCK

Исторический `P2_STANDALONE_ART_PACKS.json` сохраняется целиком. Упаковщик выбирает из него только пакеты, содержащие GLB текущих canonical `profiles.json`. Для каждой активной CC BY-SA модели должен существовать ровно один пакет с совпадающей лицензией; иначе упаковка завершается ошибкой. Каждый копируемый файл проходит прежнюю проверку размера и SHA-256.

Текущий результат: **2 отдельных SA-пакета, 9 файлов, 9 290 375 байт**:

| Внешний каталог выпуска | Состав |
|---|---|
| `art/boar-cc-by-sa-4.0/` | Действующий кабан, текстура, атрибуция с изменениями, полный текст CC BY-SA 4.0 |
| `art/roach-six-cc-by-sa-3.0/` | Шестиногий панцирник, две текстуры, атрибуция с изменениями, полный текст CC BY-SA 3.0 |

`licenses/standalone-art-packs.json` содержит квитанцию фактически выбранного набора. Старый четырёхногий Roach отдельно не копируется. Доступные производные ассеты не зашифровываются и не получают дополнительных ограничений; лицензия независимого игрового кода не меняется.

`stageGameplayCredits` сохраняет 13 файлов атрибуции/лицензий/происхождения. Существующие пути кредитов актёров, Forgotten Knight, плащей и city NPC сохранены. Природа получает `licenses/nature/CREDITS.md` из уже проверенного `art/p2-nature-sample-v3/CREDITS.md` и полный `licenses/nature/CC0-1.0.txt`. Новая дублирующая авторская атрибуция не изобреталась: документ перечисляет Poly Haven, исходные семейства и авторские изменения проекта. Масштабный Knight остаётся внешним QA-референсом и не объявляется частью nature GLB.

## Проверки и обновление пресетов

Выполнены два связанных тестовых файла, **6/6 PASS**:

```powershell
node --test tests/stage-art-packs.test.mjs tests/gameplay-export-policy.test.mjs
```

Проверены сохранение посторонних настроек и идемпотентность фильтров обоих пресетов, ссылки сохраняемых сцен, фактические байты отдельно скопированного арта и кредитов, отказ при изменённом SHA, выходе пути за пакет или отсутствии canonical SA-пакета. Первый запуск выявил только ошибку обхода каталога `.godot` в новой проверке; после исправления повтор прошёл полностью.

**Текущий `godot-pc/export_presets.cfg` этим блоком не изменён:** в нём есть предсуществующий diff. После завершения согласованного native-прогона ведущему агенту нужно выполнить из корня Pakka:

```powershell
node --experimental-strip-types scripts/world_final/prepare_gameplay.mjs --starter-v3
```

Этот штатный шаг обновит клиентские данные/версию карты и добавит фильтры. Затем — checked экспорт и проверка точного пакета в общей очереди Godot. До обновления пресетов ранее собранный EXE/PCK не получает эти исключения автоматически.
