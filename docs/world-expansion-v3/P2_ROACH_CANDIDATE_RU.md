# P2: Roach как замена панцирного существа

Подготовлен отдельный `V3RoachCandidate.glb` с родной сеткой и анимациями Roach. В штатной фабрике VarendorWorld.make_actor проверены шесть клипов, ориентация, выбор лучом, пол, удержание смерти и клиентский контракт боевых событий. Это визуальный кандидат, а не финальная художественная приёмка. После принятия основы канонический профиль MOB-05 явно переключён на Roach; прежний Shellbug сохранён как отклонённый художественный прототип. Сервер, сцены живого мира и боевые правила этим изменением не редактировались.

[Галерея](P2_ROACH_VISUAL_REVIEW.html) · [Манифест](P2_ROACH_CANDIDATE.json) · [Нативная проверка](roach-p2-evidence/ROACH_NATIVE_QA.json) · [Отдельный профиль](../../godot-pc/world-expansion-v3/actors/alternatives/roach/profile.json).

## Источник и изменения

[Roach, game-ready and animated](https://opengameart.org/content/roach-game-ready-and-animated), Danimal; исходная модель Atmostatic. Фактически скачан Roach.zip: SHA-256 `038d01360b353a4d4ebaf1e67293f8554e67ebdb06f34627cbc9538489487594`, внутри один Roach.blend. Проверены первичная карточка, полный текст CC BY-SA 3.0, архив и открытие в Blender 4.2.3 без выполнения скриптов источника.

Сохранены геометрия и UV, diffuse и normal 1024 px. Старый Blender Internal материал переведён в Principled/GLTF, roughness 0.7, сила normal 0.5. Спекулярная карта не выдаётся за metallic-карту. Высота в исходной нейтральной позе приведена к 0.45 м; origin расположен у опоры. Сетка содержит 3004 треугольника и 54 кости. Это четырёхлапое панцирное фэнтезийное существо с хвостом и шипами; естественный шестилапый жук из него не заявлен.

Исходные idle, attack2 и die сохранены. Walk использует исходное окно кадров 10–50 с масштабом времени 0.6, Flee/run — то же окно с исходным NLA-масштабом 0.35. Поэтому run 0.583 с не является придуманным ускорением для сервера. Hit — локально добавленная реакция корпуса и головы 0.333 с. Контакт атаки выбран на 42% клипа; серверное окно 0.7 + 0.7 с передаётся контроллеру отдельно. Коррекция пола запечена в риг, не перемещает серверный корень и не создаёт урон.

## Скорость и ограничения проверки

Контактные точки ClawFrontLH/RH и ClawBackLL/RL измерены в 241 фазе: медианная скорость опоры walk 0.606 м/с, run 1.039 м/с. Использованы головы исходных контактных контроллеров, а не автоматически восстановленные хвосты импортированных GLTF-костей. Последние не являются анатомическими концами лап и были исключены из расчёта. Скорости отдельных лап различаются: медиана не доказывает отсутствия локального скольжения.

Для тяжёлого раннего панцирника согласована проектная скорость 1.6 м/с. Она требует 1.541× и укладывается в неизменный предел 1.65×; верхняя поддерживаемая оценка 1.714 м/с. Прежние 3.4 м/с не подходят этому источнику. Скорость живого MOB-05 меняет интегратор в P2 backend override. Максимальный темп не повышался для сокрытия несоответствия.

Нативная сцена завершилась с exit 0: 35 проверок пройдены. Сохранены idle, контакт атаки, удержанная смерть и шесть фаз run. В этом осмотре контроллер получает скорость 1.6 м/с, а актёр остаётся в центре кадра. Сетевой pursuit, перемещение корня по реальному рельефу и расхождение с другими актёрами в живом мире здесь не проверены. Это следующий обязательный этап при явном подключении кандидата.

Оба запуска выполнены через scripts/godot_run_checked.py с предварительно созданным logfile: import 12:57:33 UTC и native 12:57:54 UTC 12 сентября 2026. Аварий не обнаружено. Журнал не чистый: недоступны user shader cache и системное хранилище сертификатов; первый запуск выявил orphan camera_controller при завершении QA. В изолированной сцене контроллер камеры теперь добавляется дочерним узлом world, как при штатном build_world. Повторный проверенный запуск 13:04:48 UTC завершился с 35/35, exit 0 и без get_path/утечек. Новые изображения не создавались; исходный журнал неудачного завершения сохранён. Сертификаты и shader cache остаются сообщениями среды.

## Распространение

Рядом с GLB лежат [полный текст лицензии](../../godot-pc/world-expansion-v3/actors/alternatives/roach/CC-BY-SA-3.0-legalcode.html), [кредиты](../../godot-pc/world-expansion-v3/actors/alternatives/roach/CREDITS.md), SHA-256 и перечень изменений. Адаптированный арт распространяется под CC BY-SA 3.0. Релиз должен включать отдельную доступную копию GLB, текстур, лицензии и кредитов вне PCK без дополнительных ограничений. Независимый игровой код этим требованием не перелицензируется. Исходный архив остаётся в частном intake.


Канонический профиль: `actors/profiles.json`, MOB-05. Модель и параметры движения соответствуют проверенному кандидату; после теста изменена только отметка статуса приёмки. Для сборщика подготовлен [манифест отдельного арта](P2_STANDALONE_ART_PACKS.json): 5 файлов, точные относительные пути и SHA-256; целевой каталог `art/roach-cc-by-sa-3.0`.



## Обязательные открытые требования к финальному MOB-05

Требование master 1178 сохраняется: шесть опорных ног, жвалы и органический хитин. Принятие этих кадров относится только к временной основе P2 development. Сейчас у Roach четыре ноги, поэтому финальный художественный gate не пройден. После кабана необходимо добавить среднюю пару с суставами, весами и реальным движением в нужных клипах либо заменить основу на шестиногую. Неподвижные декоративные ноги не удовлетворяют требованию. Жвалы и характер хитина также проверяются в итоговом игровом масштабе.

Проверка канонического профиля после удаления зависимости QA от root cached_profiles: 35/35, exit 0, без утечки/get_path, без новых кадров. Лог и результат находятся в `roach-p2-evidence/canonical-profile-check`. В этом коммите обновлён только профиль актёра; root интеграционные hooks не включены.
