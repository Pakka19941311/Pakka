# Исправление запуска смешанного старого сохранения

Ошибка поставки 25577ff02b85: `actor-geometry-home-blocked:rift-warden-arena:0`.

Старый запуск малой карты мог добавить SPAWN_REGIONS в уже перенесённый final-world и оставить finalWorldRevision. В проверенной копии присутствовали действующие четыре босса и три лишних босса старой карты. Проверка увеличенного корпуса остановила запуск на старом Rift home132,110. Свежие QA-миры этот исторический случай не покрывали.

Исправление выполняется до добавления отсутствующих точек: точные старые UID+species с существующей соответствующей популяцией переносятся из активного списка в отдельный полный архив миграции. Действующие boss UID, HP, смерть, фаза, поколение, владелец и таймеры сохраняются. Изменение не выдаёт добычу, опыт и новые предметы. Удаляются незавершённые атаки устаревших сущностей и их временные дочерние существа. Неизвестные UID, ночные существа и другие призывы не удаляются по совпадению вида.

Архив, состояние мира и предметы сохраняются одной штатной записью SQLite. До изменения launcher делает проверенный бэкап, даже если версии карты и населения уже совпали. Второй запуск не повторяет архивирование. Если существующий текущий босс отсутствует и перенос неоднозначен, обновление останавливается до записи вместо создания нового босса с полным HP. Проверка реально заблокированной геометрии сохраняется. Final-save нельзя повторно открыть через старый runtime малой карты.

На отдельной копии пользовательского бэкапа исходный упакованный сервер воспроизвёл ровно заявленную ошибку. Исправленный сервер сохранил всех пять героев, UID/количества предметов, золото, уровни/XP и четыре boss lifecycle; 102 устаревшие записи заархивированы, активных точек стало1151 с учётом150 стартовых v3. Повторная загрузка идемпотентна. Оригинальный бэкап и личная рабочая база не изменялись диагностикой.

Проверки исходников:18 целевых тестов по миграции, бэкапу, launcher и геометрии; TypeScript. Точная упакованная поставка проверяется отдельно, результаты приложены к выпуску. Клиентский EXE не меняется: исправление касается сервера и переноса сохранений. Остаток master v3 и отдельные проблемы городского прогона/дальнего переподключения этим исправлением не объявляются закрытыми.
