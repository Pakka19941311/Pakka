# Геометрия, телепорт и навигация: аудит f251

Проверена выданная сборка `f251ab9407f6`, исправление выполнено в чистом audit checkout от `6279`. Сохранения пользователя, токены и сетевые журналы пользователя не использовались и в эти материалы не включены. Новая архитектура fortress-v3 остаётся отдельным кандидатом в прежнем checkout и в исправление не входит.

## Подтверждённый дефект NAV-01

`src/world/navigation.ts` и `godot-pc/scripts/navigation.gd`: A* проверял свободные узлы, но не отрезок между ними. Ствол может пересекать ребро с двумя свободными концами. Затем smoothing, не найдя ни одного свободного shortcut, оставлял ближайшую точку без проверки. Такой путь мог вести персонажа в неподвижное препятствие.

Воспроизведение не требует сохранения: круглый ствол с центром `(-313.80376455452387, 277.5780139250065)`, радиусом `0.29169115741943535`; герой радиуса `0.46`, старт `(-310,278)`, цель `(-318,278)`, grid `1.15`, margin `24`. Старый путь соединяет `(-313.25,278.15)` и `(-314.4,278.15)` сквозь ствол. Дополнительный пример из полного packaged FinalWorld: цель `(-320,278)`, default grid, см. `invalid-segment.json`; на небезопасном ребре 56 из 101 независимых точек перекрыты коллизией.

Исправление симметрично в TypeScript/GDScript: проверка ребра A*, сохранение проверенного соединения off-grid старта с первым grid-узлом, отказ от непроверенного fallback. Прямой путь и аварийный выход также соблюдают публичную проверку сегмента. Размер сетки, радиусы, ограничения посещений и частота перепланирования сохранены. Авторская геометрия не менялась.

Проверки: Node navigation + collision **11/11**, нативный `navigation_qa.gd` через защищённый launcher **44/44**, exit 0, 0.64 с. Все прежние golden-пути сохранились; добавлены реальные лесные координаты, два размера сетки и независимые плотные пробы тела вдоль пути. В headless были только известные сообщения о недоступном root certificate store; ошибок скрипта/краша нет.

Это **не доказательство причины пользовательского отката после телепорта**. На реальных параметрах героя (grid `0.85`, margin `24`, maxVisited `4500`) отдельная выборка 77 свободных целей около точки прибытия не дала небезопасных сегментов. Общую задержку сервера исследует отдельный CPU-блок.

## Что установлено о выданном пакете

- Embedded PCK прочитан непосредственно из `Varendor.exe`: **3984 записи**. Для **59 JSON/f32** сверены PCK MD5; повреждений нет.
- **16 общих географических файлов** внутри PCK и рядом с сервером совпадают побайтно, включая D13 heightmap, terrain metadata, world_layout, все используемые collision/support слои и интерьеры. Полный список с SHA256 — `package-geometry-compare.json`. Остальные JSON/f32 являются клиентскими описаниями/источниками; их отсутствие рядом с сервером не означает отсутствующую серверную зависимость.
- **1942 import/remap** файла не имеют отсутствующих целей. **259 фактически загружаемых catalog paths** (D13 chunks, nature/groundcover LOD, distant tree atlases, P2 nature chunks) доступны через файл/import/remap. Список — `catalog-closure.json`. Поля source/native/provenance не выдавались за runtime-зависимости.
- Все **59 staged TypeScript** файлов соответствуют git f251 после нормализации CRLF. Разница переводов строк отдельно отражена в `server-source-compare.json`.
- `generated/game.json` из EXE и настоящий packaged FinalWorld имеют одинаковый `mapVersion`: `world-final-gameplay-1-starter-v3-6eb514fed530fa796385d3fea9c65b4f014ef4b183d6d42b4046b57005e205ee`. Сервер строит 20064 статических препятствия и 462 support-поверхности.
- «Чёрный лес»: server `(-310,+278)`, Godot `(-310,Y,-278)`, L03, высота `107.667259`, склон `25.293789°`, свободен для радиуса `0.46`. Поиск прибытия координаты не сдвигает. Остальные три штатных телепорта также свободны (`arrival.json`).

## Прочитанный runtime и границы вывода

Прочитаны `src/world/{final-world,collision-world,navigation}.ts`, `src/controls/character-motor.ts`, teleport/relocate/waypoint в `src/server/world-simulation.ts`; клиентские `world.gd`, `player_movement.gd`, `snapshot_timeline.gd`, `network.gd`, `collision.gd`, `navigation.gd`, `support_height_index.gd`; `world-final/gameplay_environment.gd`, `nature_layer.gd`, `groundcover_layer.gd`, `tree_focus.gdshader`, `graphics_profile.gd`. Для расследования f251 использован `git show`, не текущие незакоммиченные файлы старого checkout.

Телепорт в лес остаётся в `surface`: все D13 чанки/коллизии были загружены при первоначальном `activate_space`, повторной загрузки тайлов при этом переходе в данном коде нет. `relocate` сбрасывает motor/control/path и увеличивает generation; timeline отвергает старшую по времени, но более старую generation; player prediction сбрасывает историю и визуальную коррекцию на смене generation. Смена поколения не должна интерполировать путь от города к лесу. Установленного нарушения координатного знака или несовпадения support-формулы в этом участке не найдено.

Остаются за рамками этого короткого блока: графическое воспроизведение пользовательского зависания, стоимость GPU в лесу, фактические draw calls нового пакета, полная топология каждого импортированного меша, визуальная приёмка всех зон/интерьеров. Closure проверяет существование ресурсов, а не художественное качество. Архитектурный кандидат и новые рендеры остановлены по приоритету hotfix. Оптимизация серверного `FinalTerrain.supportAt` принадлежит другому блоку; этот коммит её не содержит.
