# Готовность ресурсов облачной сборки P2

Проверено 12 сентября 2026, 18:21 UTC. Полная сборка, Godot, Blender и push
не запускались. Новый город согласован с world_plan_audit после его коммита
`82b8c5d`; исходники города после этого не менялись.

Найден и устранён конкретный конфликт: 21 файл нового озера/рельефа уже был
в Git, но `materialize_payload.py` знал только его старый SHA. При облачном
checkout восстановление отказалось бы перезаписывать неизвестную новую
версию. Добавлен двенадцатый неизменяемый слой `p2-terrain-lake-20260912`:
21 файл, 5 частей, 15 605 977 байт. Старые слои и проверка сохранения ручных
изменений не ослаблены. Каждый член нового ZIP сравнен с текущим файлом
побайтно; SHA архива и всех частей проверены. В итоговом manifest новые
версии теперь признаны опубликованными, поэтому старый слой их не заменит.

Слой содержит `geography/landmarks.glb`, общие опоры, 16 изменённых чанков D13,
`heightmap.f32`, `terrain-data.npz` и метаданные D13. Эти расширения исторически
игнорировались через `geology-D13/.gitignore`, но изменённые экземпляры также
явно включены в Git коммитом `2204ded`. Дублирование здесь нужно для корректной
истории восстановления слоя, а не для замены текущего файла старой моделью.

Пять активных GLB из canonical profiles, `courtyard-p2.glb`,
`courtyard-p2.json` и `Greenfall_Courtyard_P2.blend` отслеживаются Git.
Для них отдельное дублирование в старом geography payload не требуется.
Проверены также runtime каталоги city/actors/cloaks и P2 nature: новых GLB/f32
вне Git и вне manifest не найдено. Проверенные активные GLB не ссылаются
на внешние отсутствующие изображения; встроенные изображения извлечёт
обычный импорт в облачной сборке.

В экспортной политике сохранены исключения cohort 06–10 и отвергнутых моделей.
Добавлено только `world-expansion-v3/actors/models/V3StarterSlime*`: этот старый
вариант больше не загружается retained-сценами. Активный путь
`world-expansion-v3/actors/production/V3FacelessSlime.glb` остаётся в пакете.
Обе существующие проверки экспортной политики прошли, включая обход literal
ресурсных ссылок и все пять canonical profiles. Старые общие модели, нужные
legacy-потоку, широким шаблоном не исключались.

`package_geography.py --paths-file <JSON-массив путей>` позволяет записать
ограниченный проверяемый слой без упаковки всех исторических Blender-мастеров.
Пути проверяются на принадлежность репозиторию и допустимый тип. Внешний
полный restore 11 старых слоёв не повторялся; перед обновлением сравнивались
929 текущих конечных файлов с manifest, недостающих не было.

Перед Windows/cloud экспортом root запускает обычный
`node scripts/world_final/prepare_gameplay.mjs --starter-v3`: он обновит
mapVersion и включит дополнительный exclude. `export_presets.cfg` этой
проверкой не переписывался. Подробные SHA и активные пути сохранены рядом
в `P2_PAYLOAD_READINESS.json`.
