## RESPONSE-LIVE-001 — поведение

Для трёх существующих видов новый реестр `src/data/ranged-response-v3.ts` содержит только приём: aimed-line16м, cooldown7с, windup1,2с, recovery1,6с, halfWidth0,9м, raw существующий ATK×1,2, magic/fire либо magic/ice. Начало и конец фиксируются до замаха, конец обрезается препятствием/terrain. На impactAt — один направленный импульс; проверяются capsule с телом героя, нынешние LOS, space, generation, safe и leash. Одно release и максимум один hit по выбранному герою. Попадание использует MDEF через прежнюю формулу защиты героя; нет второй slash-атаки.

Counter готов только вне контактной зоны и при доступном cooldown. Между приёмами монстр продолжает обычное преследование, не стоит на16м. Во время замаха поворачивается к сохранённой точке, не наводит линию вслед за бегущим героем. Существующий единый pending не допускает параллельную контактную атаку. Потеря LOS/непопадание не восстанавливают HP; возврат по прежнему leash остаётся отдельным переходом. Урон призыва провоцирует его владельца.

Cave в candidate mode сохраняет13м, круг4м, замах1,4с, полную анимацию1,9с и прежний физический удар×1,4. Проверка `nextSlamAt` теперь работает: начала кругов не чаще9с. Между ними настоящий контакт до2,29м, без невидимого13-метрового slash. Это заметное исправление прежней фактической частоты2,4с, не скрытая перенастройка остальных режимов.

## RESPONSE-LIVE-002 — точный additive wire

Новый groundEffects элемент:

```json
{"id":"monsterUID:counter:generation:hitAt","kind":"line","owner":"monsterUID","point":{"x":0,"z":0,"spaceId":"surface"},"endPoint":{"x":16,"z":0,"spaceId":"surface"},"radius":0.9,"halfWidth":0.9,"expiresAt":1200,"effect":"fire"}
```

Пример выше показывает формат, а не игровые координаты. Реальный объект находится в `RANGED_RESPONSE_CONTROL.json → stationary[0].ground`. Полоса с закруглёнными концами имеет именно halfWidth0,9м; radius сохранён для общего wire-типа. После release/cancel/death pending исчезает и элемент пропадает из snapshot. Из другого space не передаётся. ID постоянен внутри одного замаха.

События attack/release содержат additive `attackKind:'aimed-line'` и `halfWidth:0.9`. Сохраняются actor/target/generation/actorGeneration, origin/destination с абсолютным y, effect fire/ice, attack impactAt/endsAt. У release durationMs0: это импульс по фиксированной линии, не существующий homing Projectile. Нативный индикатор разрабатывается отдельным агентом; текущее серверное доказательство не разрешает рисовать вместо линии круг.

## RESPONSE-LIVE-004 — границы проверки

Целевые тесты проверяют настоящий контакт/уклонение, не homing; физическую стену после начала замаха, обрезку дальнего конца, преследование между cooldown, invalidation при смерти/space/generation/cancel, cave cadence/melee, неизменный legacy mode и четыре boss records. Искусственная стенка — отдельный collision-fixture, явно не новый объект реальной карты.

Перезапуск отменяет незавершённый counter, но сохраняет оставшееся игровое время `nextCounterAt`: три дня закрытого процесса не превращают оставшиеся7с в готовую атаку. Проверен полный состав1151 и четыре сохранённых крупных босса. Настоящий переход death→respawn увеличивает generation и очищает старый `nextCounterAt`; старый aim не исполняется, повторной добычи нет. Этот тест вызывает серверную смерть как отдельный lifecycle fixture, затем штатный disconnect/catch-up до исходного respawnAt: он не выдаётся за полный бой или непрерывную минуту патруля.

Проверки: `tests/ranged-response-v3.test.mjs` —13/13 PASS; связанные `book-typed-damage`, `stage-cave`, `core-gameplay-server`, `combat-feedback` —41/41 PASS; TypeScript `tsc --noEmit` PASS. Новый контрольный драйвер повторён после окончательной серверной правки: sourceHashes не менялись во время прогона, результаты таблицы воспроизведены. Ранняя синтетическая проверка отмены смерти обнаружила некорректный fixture (`alive:false` с прошлым respawnAt), который теперь использует настоящий серверный переход смерти; production под него не ослаблялся.

Godot этот агент не запускал. Уровни/защита поздних противников и полные бои58/66 остаются следующим отдельно принимаемым блоком. Отсутствие дальнего ответа исправлено в кандидате; низкий legacy уровень/нулевая DEF/MDEF и raw процентные книги по-прежнему не дают объявить весь будущий high-level баланс готовым.
