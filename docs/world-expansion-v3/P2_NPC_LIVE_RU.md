# Два NPC на существующих городских маршрутах

В режиме `--starter-v3` патрульный Ольгер (`ambient:103`) и горожанин Освин (`ambient:115`) используют модели MPFB из `09ccecf`. Все прежние 39 жителей, 13 служебных NPC, имена, роли, маршрутные точки и скорость сохранены. Позицию и поворот по-прежнему задаёт единственный существующий симулятор жителей. Фаза шага рассчитывается по действительно показанному расстоянию, включая отложенные обновления далёких моделей. В остановке используется idle, на существующей разговорной точке — talk. Обычный контроллер анимации не управляет тем же скелетом параллельно.

`p2-npc-live-03`: 23/23 условий, 90.219 с, exit 0. Патрульный прошёл 19.22 м, житель 10.91 м по неизменённым маршрутам; наблюдались ходьба и остановки у обоих, разговор жителя у колодца. Проверены свободная поверхность, отсутствие попадания в стены, правильная высота/масштаб, развитие фазы походки. Три итоговых кадра просмотрены. NPC не телепортировались и не получили подставленные фазы. Для кадра перемещался только наблюдатель через серверную QA-позицию; проверка следования самого игрока за патрулём этим не заявляется. Наблюдатель в синтетической базе без надетой брони, это не изменение экипировки игроков.

Две предыдущие попытки не получили нужные кадры: автоматическое следование наблюдателя использовало неудачные точки у стен. Они не считаются успешной визуальной проверкой. Заключительный прогон выполнен без падения, GDScript-ошибок и утечки объектов при закрытии; остаются известные предупреждения shader cache и сертификатов среды.

Дополнительно исправлена регистрация размеров: локальные модели NPC не остаются в общем списке генерируемых монстров после создания. `p2-npc-factory-02` создал оба типа в двух последовательных экземплярах мира — 8/8, 2.718 с, exit 0, без утечки. Это последующая узкая проверка изменения фабрики; основные живые маршруты проверены до этой поправки. В первой проверочной сцене не был присоединён к дереву штатный контроллер камеры; исправлена только сборка проверочной сцены.

Произвольные развороты на месте и движение по лестницам ещё не приняты как новая анимационная система. Изолированные клипы поворота на 90° не подключены поверх старого произвольного yaw: это нарушило бы опору стоп. Полная замена городских людей остаётся следующим этапом. Доказательства: `npc-live-evidence/`. Лицензии моделей и производных деталей включаются в упаковку.
