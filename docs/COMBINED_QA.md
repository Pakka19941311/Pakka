# F — единый блок и замечания владельца

База: `105af3e5`, рабочая ветка `work/v06-commercial-rebuild`. Владелец разрешил следующий блок вместе с замечаниями одной сдачей. `main` не меняется; после ZIP — `awaiting_user_test` и остановка.

Проверки соразмерны изменению. Для предыдущей небольшой выдачи свитков повторение всей браузерной матрицы A/B/C/E/D было избыточным. Здесь изменяются управление, расчёт предметов, выбор цели и геометрия, поэтому проверяются именно эти связи. Старые сценарии остаются доступными в репозитории, но повторные циклы смерти/респавна, все прежние размеры HUD и полный обход классов в обязательный прогон не входят.

## Обязательные проверки

- Модульные тесты: целочисленные прибавки предметов +0…+15, точность и границы редкого MISS, выбор цели и препятствия, изменения ввода. Существующий быстрый набор unit-тестов запускается целиком.
- TypeScript, production build и верификация ресурсов. NullEngine проверяет реальные загрузчики/ресурсы, но не подтверждает управление или внешний вид.
- `F-production-combined.json`: реальная скачиваемая бета-сборка, обычные события клавиатуры и мыши; W остаётся зажатой при обоих переключениях Tab; только девять видимых характеристик; четыре стака по 100; одна безопасная заточка; reload сохраняет результат и не повторяет выдачу; обмена нет; QA-фикстуры отсутствуют.
- `F-combined.json`: отдельная QA-сборка, те же обработчики и реальные world update ticks. Tab во время W, пути к точке, преследования, melee-замаха и магии; единственный выпуск/списание навыка. Адресная проверка выбора живого монстра рядом с силуэтом и блокировки стеной. Три вида настоящей геометрии: подход к воротам, двор и навес кузнеца. Математические таблицы покрываются unit-тестами, а не сотнями кликов через браузер.
- Windows PowerShell launcher: реальный старт HTTP-сервера, HTML, JavaScript MIME/маршруты и полный GLB.
- Gate упаковки требует оба отчёта с `passed=true`, пустыми `errors`, непустыми `checks` и точным `GITHUB_SHA`. ZIP содержит production-файлы, launcher, инструкцию, оба отчёта и полный SHA; проверяются архив и SHA-256. Изолированные QA-фикстуры не попадают в игру.

Браузерный стенд: Chromium software WebGL, 1280×720, Low и render scale 50% для ограниченного CI-стенда. Это проверка загрузки, поведения и геометрии, не аппаратный FPS-бенчмарк и не обещание производительности на GPU пользователя. Скриншоты сохраняются отдельным QA-asset того же GitHub Release. Фактические результаты и ссылка на CI дописываются ниже только при успешной упаковке.
