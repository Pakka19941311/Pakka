# QA Report — Varendor v0.4 Phase 1

Дата проверки: 2026-09-03.

## Результат этапа

Phase 1 «Camera / Input / Combat Control Foundation» завершён. Основной режим камеры заменён на плавную third-person камеру. Ручное движение, click-to-move, явный выбор цели и управление боевым преследованием разделены на самостоятельные контроллеры. Локальный клиент отправляет нормализованные movement intents через заменяемый `GameGateway`, сохраняя границу для будущего server-authoritative movement/combat.

## Автоматическая валидация

- 26 тестов игровых правил, control foundation, сохранений, gateway и source contracts: пройдены.
- TypeScript typecheck: пройден.
- Production build Vite: пройден.
- Проверка 5 моделей персонажей, 4 моделей монстров и 21 модели окружения: пройдена.
- Проверка 21 внешней ссылки GLB/glTF: пройдена.
- Production HTTP runtime smoke: пройден.
- Загрузка, создание экземпляров, анимации и bounding boxes всех игровых моделей через Babylon.js: пройдены.
- Сохранения не мигрировались на новый несовместимый ключ: существующий прогресс v0.3 продолжает читаться.
- Регрессия прогрессии, предметов, экипировки, заточки, классов, боссов, дропа и локального persistence: пройдена.

## Ограничение среды

В Work-среде отсутствуют Chromium/Firefox, поэтому новый GPU-визуальный проход и субъективная оценка ощущения камеры здесь не заявляются как выполненные. Production runtime, сетевые границы, управление состояниями, HTTP-раздача и загрузка ассетов проверены автоматически. Финальная оценка композиции кадра и чувствительности мыши остаётся визуальным игровым тестом владельца продукта.
