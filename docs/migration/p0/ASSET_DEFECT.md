# P0-ASSET-001 — повреждённая текстура в исходном Git

Полное декодирование **119** изображений из `public/assets`: **118 pass, 1 fail**. Ошибка — `public/assets/models/world/Textures/colormap.png`, 1492 байта, SHA-256 `5a447c9fb2027907f5e2e8bed8caf08d2b3d3e261cb39fe605cca0b2c309d9a9`. Локальные байты и `git show HEAD:<path>` совпали. PNG объявляет IDAT длиной 1741 байт, но файл обрывается раньше конца этого блока. Pillow и Blender/libpng не декодируют изображение.

На текстуру ссылаются **21 GLB**; полный перечень — [image-decode-audit.json](evidence/image-decode-audit.json). Это число ссылок, не доказательство того, как все эти объекты выглядят в текущем браузерном мире: runtime может назначать свои материалы. Дефект не объявляется причиной FPS/камеры или всех прежних UV-замечаний.

Проверена доступная история этого пути: `152ad442` и `9b564e96` содержат нечитаемую версию; в `55fbae95` файл отсутствует. Исправная копия в просмотренной истории не найдена. Исходник сохранён без подмены или попытки угадать недостающие пиксели. Для восстановления нужен целый исходный файл с подтверждённым происхождением; альтернативный внешний ассет автоматически не подставляется.

Проверка: `python scripts/p0-image-audit.py` (Pillow 12.3.0). Сейчас ожидается exit **1**, поскольку дефект открыт. Утилита только читает ассеты и пишет отчёт. Прежний `verify-assets` проверял наличие/ссылки и мог завершаться успешно — это не подтверждало чтение PNG. Инвентаризация и контрольные суммы baseline остаются верными, вывод о декодируемости дополнен этим дефектом.

P0-05 использует другой существующий Git-ассет — деревянный ящик с исправными PBR-текстурами. Это технический образец, не исправление/замена моделей мира.
