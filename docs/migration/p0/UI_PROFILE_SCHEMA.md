# P0-03 — интерфейс и профиль

Источник: `src/main.ts`, `src/ui/character-inventory.ts`, `src/inventory.css`, `src/controls/quickbar.ts`, `src/network/remote-world-gateway.ts`, принятые QA-документы на baseline. Это описанная схема, не выгрузка профиля Никиты.

| Ключ browser storage | Содержимое / обращение |
|---|---|
| varendor_client_settings_v1 | Настройки UI/графики/звука; quickbar[32] из action/key, quickRows 2/4, inventoryWindow, uiScale, keybinds, громкости. Сохранить фактические значения. |
| varendor_world_profiles_v1 | Список id/name/classId/token. Секретный материал; только в закрытую копию. |
| varendor_world_token_v1 | Bearer выбранного героя; не помещать в Git/отчёт. |
| varendor_world_pending_v1 | Исходный id и command. После подключения получить прежнюю квитанцию; новый commandId не создавать. |
| varendor_world_import_pending_v1 | Незавершённый id/save бета-импорта; приватно, не повторять другим id. |
| varendor_world_import_backup_v1 | Предшествующая копия локального сохранения; приватно. |
| varendor_reborn_v03 / varendor_reborn_v02 | Legacy-сохранения, возможная другая стадия того же героя; не импортировать дважды. |

Снять точный origin браузера, имя используемого профиля и выбранного героя. `localhost:4173` и `127.0.0.1:4173` — разные источники browser storage. Серверная таблица sessions содержит хеши, из неё нельзя восстановить исходный bearer. Наличие SQLite не доказывает сохранённый вход.

UI: базовое окно из CSS 392×564 px до transform/масштаба, 6 колонок / 42 ячейки / 3 видимых ряда; equipment 3×4. Положение хранится отдельно, ограничивается доступной областью. Tooltip: база/бонус/итог, фактическая разница, общий resolver парных слотов. Значения CSS не выдаются за измерение на экране.

| Действие | Зафиксированное правило |
|---|---|
| Tab / I / C | То же компактное окно; event.repeat не переключает его повторно. Мир не ставится на паузу. |
| Esc | При текстовом фокусе снимает фокус; затем приоритет редактирование панели / подтверждение / отмена заточки / drag / верхнее окно / настройки. Один нажим — одна обработка. |
| WASD, ЛКМ земля | Ручной путь/движение отменяют автоподход; выделенная цель может оставаться. |
| ЛКМ враг, ПКМ, колесо, Space | Target-атака, вращение, zoom, прыжок. |
| Q/E | ConsumableBindings; индивидуальные назначения сохраняются. Не перепутать с Shift+KeyQ/E в quickbar. |
| Конфликт быстрых клавиш | UI отказывает повторному назначению; normalizeQuickbar сохраняет первый дубликат, очищает последующий key. |
| Фокус ввода текста | Игровые сочетания не исполняются; вход в текстовое поле сбрасывает движение. Это отличается от открытия сумки. |
| Double click / drag | Одно действие / перемещение UID. Drag не превращается в использование. |
| Свиток → предмет | Double click выбирает свиток, single click отправляет одну операцию; результат по receipt. |
| Полная сумка / два кольца | Обмен 1:1; снятие без места отклоняется. Явный совместимый слот → свободный → первый из пары. |

Для будущих парных кадров нужны HUD 2/4 ряда, сумка, экипировка, длинный tooltip, режим заточки; контрольные состояния: полная сумка, парные кольца, +N, четыре свитка, последняя единица расходника. Новые фикстуры не выдавать за вещи владельца.

Сейчас доступны два исторических кадра видео от 07.09 (8 и 45 сек.): только HUD с двумя рядами. Commit записи и output/display resolution не подтверждены; файл видео 3262×1834, overlay рендера 1821×1034. На этих кадрах нет полного набора P0-03.1. Новый browser runtime заблокирован `ERR_BLOCKED_BY_CLIENT`; кадры актуальной сборки, матрица разрешений и экспорт личного профиля остаются blocked.
