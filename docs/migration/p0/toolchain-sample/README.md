# P0-05 — изолированный технический образец

## Android-продолжение

После `c4a88e8` добавлен отдельный preset `P0 Android` и настройки мобильного импорта/Compatibility в этом образце. Подписанный ARM64 APK проверен; [отчёт, команда и ограничения](../ANDROID_EXPORT.md). Установки на устройство не было. Ниже сохранены результаты прежнего Linux/Blender цикла на его тогдашней конфигурации; они не выдаются за повторный Linux тест изменённых настроек.

## Ранее проверенный Linux/Blender цикл

Это проверка инструментов, не новый клиент Varendor и не изменение мира. Модель и три текстуры взяты из существующих Git-ассетов Poly Haven `public/assets/models/realism/wooden_crate_01`; из трёх мешей выбран наиболее подробный `wooden_crate_01`. Лицензия и происхождение остаются указанными в действующих документах ассетов.

## Что проверено

- Blender **4.5.9 LTS**, build **8bf95cbd38d1**: повторяемый запуск из полной распаковки во временной папке, импорт, UV, три читаемые текстуры 1024×1024, метрический масштаб, простая анимация поворота.
- `.blend` с упакованными изображениями → два экспорта GLB → повторное чтение Blender. Исходные и обратные размеры совпали: **0.8252729 × 0.4083103 × 0.3219084 м** в осях Blender. Получен и визуально просмотрен кадр **Cycles CPU**, 480×480, 16 samples.
- Godot **4.6.3.stable.official.7d41c59c4**, typed GDScript: текстура 1024, UV, размеры **0.8252729 × 0.3219084 × 0.4083103 м** в осях Godot; отдельная коллизия реально отвечает на physics ray. Анимация `P0Rotate` меняет поворот меша.
- Изменён GLB (только технические metadata), выполнен повторный импорт: настройка внешней сцены сохранилась. Проверка повторена из чистой временной папки без кэша и извлечённых JPG — необходимые файлы созданы импортёром заново.
- Export templates **4.6.3.stable**: Linux x86_64 release с встроенным PCK собран и запущен отдельным процессом. В экспортированной программе те же проверки завершились `P0_SAMPLE_PASS`, exit **0**.

Суффикс `-colonly` используется по [официальной документации Godot](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/node_type_customization.html). Видимый коллизионный меш после импорта исчезает, остаётся физическая форма. Это грубый технический параллелепипед, не коллизия будущего игрового предмета.

## Воспроизведение

1. Получить официальные Blender 4.5.9 и Godot 4.6.3, Linux export templates 4.6.3.stable; точные источники/контрольные суммы — `../evidence/toolchain-distributions.json`. Использовать полную проверенную распаковку; прежняя распаковка в scratch имела неполные файлы. Причина тех обрывов не установлена.
2. Из корня репозитория: `blender --background --factory-startup --threads 2 --python-exit-code 1 --python scripts/p0-blender-probe.py`. Скрипт создаёт .blend, два GLB, CPU-кадр и отчёт. В журнале Blender есть предупреждение об общем image sampler; текстуры проверены после повторного импорта, визуальные различия sampler в Godot не оценивались.
3. Сохранённый `godot/p0-crate.glb` отличается от первого Blender-экспорта только технической ревизией в `asset.extras`, добавленной для проверки reimport. Геометрия/материал/анимация сохранены. Перенос исходного Blender GLB в эту папку также допустим при повторении скрипта.
4. Установить стандартные Linux templates и выполнить `python scripts/p0-godot-probe.py --godot /полный/путь/Godot`. Скрипт делает чистую копию проекта во временной папке, проверяет импорт/reimport, экспортирует и запускает отдельный executable. Логи и итог записываются в `../evidence/godot-clean-*`.

В Git сохранены исходный .blend, один GLB для Godot, CPU-кадр, сцена/скрипт/настройки экспорта и свидетельства. Вспомогательные повторные GLB, кэш импортёра, извлечённые JPG и программы инструментов заново создаются и не дублируются в Git. Хеш экспортированного executable — в `../evidence/godot-clean-probe.json`; сам 76-МБ технический executable не является новой игровой Windows-сборкой и не публиковался как Release.

## Предел проверки

**Графическое окно и реальный рендер Godot не проверены**: headless использует режим без окна. Xvfb отсутствует; установка пакета остановилась на системных setgroups/setegid permissions. Это не GPU-профиль и не FPS Varendor. Blender CPU-кадр не выдаётся за кадр Godot. Windows/Android/iOS export/install не выполнены. Анимация здесь — технический поворот, не скелетная анимация героя. Личные данные не читались. P1 не начат.
