# P0-01.2 — сверка решений

Проверены ТЗ v2.0 целиком, START_HERE/STATE исходного пакета, PROJECT_RULES, DECISIONS, принятые блоки HUD/INVENTORY/ENHANCEMENT/ITEM_PROGRESSION_V3, план REBUILD_THREE_PARTS, соответствующие положения MASTER_GDD и актуальные исходники. Контроль — `88838a79`.

| Историческое положение | Применяемое решение |
|---|---|
| MASTER_GDD: клиент только в браузере | Последнее решение: Godot native + Blender. Старый браузер остаётся контрольной версией. |
| Старые DECISIONS/PROJECT_RULES: сервер ещё не реализован | На baseline есть HTTP/SSE, авторитетная симуляция, SQLite и receipts. Публичные аккаунты и хост 24/7 этим не доказаны. |
| MASTER_GDD / DECISIONS: безопасно до +3 для всех | Действующие V2: оружие +3, обычная броня +1, улучшенная броня +2. Сверены все 60 чисел. |
| Ранние дробные множители усиления | ITEM_PROGRESSION_V3 и текущий item-progression.ts: целые прибавки. В ТЗ слово «нелинейные» не возвращает старые формулы. |
| Старый порядок трёх визуальных частей | ТЗ P0–P6; мир → герои/NPC → противники сохранены внутри P1–P3. P1 включает перенос прежних функций. |
| Старые четыре выбранные модели троллей/големов | Новые эталоны и собственное производство; сохраняются десять видовых ID, в том числе spider. Подмена вида удобной моделью запрещена. |
| Телефоны позднее | Ранний физический тест P1-05, доводка P5. Отсутствие Mac/iPhone отмечается blocked. |
| GDD: PvP с 30 уровня, торговля и MMO-цели | Backlog, не функции нынешней сборки. P0 их не реализует. |
| STATE исходного пакета: execution_authorized=false | Прямое сообщение владельца разрешает P0. Корневой STATE отражает это разрешение. |
| Старые QA требуют повтор всей матрицы A–F | Последнее правило: проверяется текущий блок и конкретные затронутые связи. Здесь сборка baseline и тесты процедуры копирования, без полного старого QA. |

Сохраняемые факты экспортированы из действующих модулей в `evidence/gameplay-contract.json`: пять классов, 20 навыков, 33 определения предметов, десять видов, 12 слотов, 32 назначения, четыре свитка, все вероятности и прибавки. Это каталог правил и исходных значений; личный профиль/собственность он не заменяет.

Дополнительное расхождение охвата: текущий UI предлагает scale 80–125%, ТЗ требует проверок до 150%. 150% остаётся требованием переноса, не ранее проверенным режимом. Полная таблица 1080p/QHD/4K не закрывается скриншотом из видео.
