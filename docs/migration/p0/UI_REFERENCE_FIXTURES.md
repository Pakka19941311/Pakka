# P0-03.4 — контрольные предметы и состояния

Это **синтетический набор сравнения**, не сохранение владельца. Игровые файлы не менялись. Набор не является форматом импорта персонажа и не отправляется в игровой сервер/браузер. Все определения предметов, слотов, шансы и расчёты берутся непосредственно из существующего TypeScript-кода.

[Данные](evidence/ui-reference-fixtures.json), [результат проверок](evidence/ui-reference-checks.log.txt), [генератор](../../../scripts/p0-ui-reference.mjs).

| Состояние | Содержимое / ожидаемый результат |
|---|---|
| Полная сумка | 42 вещи, непустые уникальные синтетические UID. Обмен кольца 1:1 сохраняет размер сумки и набор UID; снятие оружия без места отвергается `bag-full`. |

Проверки не изменяют входной образец. Успех и неудача заточки — два **раздельных** тестовых состояния с заданными значениями roll; это не повтор чужой операции и не измерение вероятностей. Реальные server receipts/pending здесь не создаются; идемпотентность ранее проверялась отдельно в P0 backup/shutdown.

Команда: `node --experimental-strip-types scripts/p0-ui-reference.mjs`. Проверены **12 условий**; это один генератор с assertions, не 12 отдельных браузерных тестов. Все 60 шансов сверены с исходным ТЗ BASELINE. Полный QA игры не повторялся, поскольку игровые файлы не менялись.

P0-03.4 технически подготовлен/проверен в объёме фиксации контрольных предметов. **P0-03.1 и P0-03.3 остаются незавершёнными**: свежие кадры, размеры/положения окон, UI-scale и реальный профиль не получены. Следующий шаг — использовать эти же состояния при доступной визуальной проверке прежнего клиента и затем Godot. Нельзя выдавать JSON за UI-кадры или импортировать его в личный мир.
