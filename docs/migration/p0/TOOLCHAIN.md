# P0-05 — фактическая доступность

Среда проверки: Linux x86_64, Node 24.19.0, npm 11.9.0, OpenJDK 17.0.20. Драйвер/игровой GPU владельца неизвестны. `/dev/dri` в доступной среде отсутствует.

| Компонент | Факт | Что не закрыто |
|---|---|---|
| Старый TypeScript/Babylon клиент | npm ci по lockfile; production build прошёл | Новый визуальный runtime в Browser не открыт: ERR_BLOCKED_BY_CLIENT на локальном адресе |
| Godot | Исполняемый файл не обнаружен; получение официальной сборки не завершено: сетевой запрос отменён механизмом разрешений | Запуск редактора, реальный render, templates и экспорт |
| Blender | Исполняемый файл не обнаружен; индекс официальных дистрибутивов доступен | Установленная версия, .blend → GLB с материалом/анимацией |
| Android | Java runtime 17 есть; javac/adb/sdkmanager не обнаружены | SDK/JDK, templates, подпись, установка на физический телефон |
| iOS | Linux; Mac/Xcode/физический iPhone не предоставлены | Экспорт, подпись и физический запуск |
| Typed GDScript | Принятое направление клиента | Не создан новый игровой клиент |

Для проверки кандидата использованы [официальный архив Godot 4.6.3](https://godotengine.org/download/archive/4.6.3-stable/) и [официальный индекс Blender 4.5](https://download.blender.org/release/Blender4.5/). Это доступные сведения о дистрибутивах, не установленная toolchain. Версии нельзя объявлять закреплёнными до успешного цикла.

Технический образец P0-05.2 не изготовлен: полный путь Blender→GLB→Godot не доступен. Предстоящая проверка: единица масштаба, UV, материал/текстуры, простая коллизия, одна анимация, повторный экспорт без потери игровых настроек. Это отдельный технический образец, не начало P1 и не замена утверждённого мира.
