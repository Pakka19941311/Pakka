# P0-05 — актуальное состояние после 2b02d40

**Рабочий технический цикл подтверждён:** Blender 4.5.9 LTS → GLB → Godot 4.6.3 → Linux release executable → headless-проверки. [Образец и воспроизведение](toolchain-sample/README.md), [точные дистрибутивы](evidence/toolchain-distributions.json), [чистый запуск](evidence/godot-clean-probe.json). Typed GDScript, масштаб/UV/текстура/анимация/коллизия и сохранение внешней настройки при reimport проверены.

P0-05.2 технически проверен в указанном объёме. P0-05.1 остаётся частичным: есть Blender CPU-render, но нет графического Godot render/editor acceptance. Windows/Android/iOS не проверены. Пакет Xvfb установить не удалось из-за системных setgroups/setegid permissions; обход ограничений не выполнялся.

При первом образце установлена отдельная причина отказа материала: повреждённый PNG уже в Git, см. [P0-ASSET-001](ASSET_DEFECT.md). Исправный образец прошёл повторный импорт. Прежние сбои исполняемых файлов и их причина не смешиваются с этим дефектом текстуры.

# P0-05 — фактическая доступность

Среда проверки: Linux x86_64, Node 24.19.0, npm 11.9.0, OpenJDK 17.0.20. Драйвер/игровой GPU владельца неизвестны. `/dev/dri` в доступной среде отсутствует.

| Компонент | Факт | Что не закрыто |
|---|---|---|
| Старый TypeScript/Babylon клиент | npm ci по lockfile; production build прошёл | Новый визуальный runtime в Browser не открыт: ERR_BLOCKED_BY_CLIENT на локальном адресе |
| Godot | Исполняемый файл не обнаружен; получение официальной сборки не завершено: сетевой запрос отменён механизмом разрешений | Запуск редактора, реальный render, templates и экспорт |
| Blender | Официальный архив 4.5.9 LTS скачан и проверен по SHA-256; один запуск --version и headless-чтение GLB прошли, повторные запуски аварийны | Надёжно работающая установка, render и .blend → GLB с материалом/анимацией не подтверждены |

Для проверки кандидата использованы [официальный архив Godot 4.6.3](https://godotengine.org/download/archive/4.6.3-stable/) и [официальный индекс Blender 4.5](https://download.blender.org/release/Blender4.5/). Это доступные сведения о дистрибутивах, не установленная toolchain. Версии нельзя объявлять закреплёнными до успешного цикла.

Технический образец P0-05.2 не изготовлен: полный путь Blender→GLB→Godot не доступен. Предстоящая проверка: единица масштаба, UV, материал/текстуры, простая коллизия, одна анимация, повторный экспорт без потери игровых настроек. Это отдельный технический образец, не начало P1 и не замена утверждённого мира.

## Продолжение проверки Blender после 2d9b0c4

[Свидетельство](evidence/blender-attempt.json): официальный архив 377 929 956 байт проверен по опубликованному SHA-256. После распаковки обнаружены неполные файлы. Повторная сверка библиотек/исполняемого файла выявила четыре несовпадения. После их восстановления и проверки в одном процессе один запуск подтвердил Blender **4.5.9 LTS**, build **8bf95cbd38d1**.

Техническая попытка использовала `public/assets/models/world/wall-arch.glb` непосредственно из Git. Blender сообщил об импорте GLB; проверка загруженных данных текстуры завершилась отказом. Готовых .blend/повторно экспортированных GLB или кадров render не получено. Повторные запуски завершались SIGSEGV/SIGBUS; причина нестабильности среды пока не установлена. Установка не считается рабочей, версия не закреплена для проекта.

Следующая инструментальная проверка: среда, сохраняющая целостность распакованных файлов и обеспечивающая повторяемый запуск Blender; затем материал/UV/масштаб/анимация и полный импорт Godot. Не подменять этот результат успешным pipeline. Скачивание программы само по себе P0-05.1 не закрывает.
