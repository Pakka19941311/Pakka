# Ограничения диагностики

server_probe.mjs запускается через Node с поддержкой удаления TypeScript-типов; аргументы: абсолютный путь к репозиторию контрольной версии и путь JSON-отчёта. Импортирует существующее ядро, создаёт только временные базы. Это синхронный микрозамер без реальных HTTP-клиентов, сетевой задержки, массового боя и рендера. Не является измерением FPS пользователя или гарантий онлайна. Описание и таблица находятся в ТЗ.

На просмотренных кадрах ранее предоставленного видео видны 13–18 FPS, p95 около 104–124 мс, рендер 1821×1034. Это показатели клиентского кадра. Они не доказывают причину серверного лага. Исходное видео остаётся отдельным пользовательским вложением и не дублируется в архиве.
