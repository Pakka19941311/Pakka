# Первый интеграционный тест Godot для ПК

Рабочий код: `1dcd61ffd8c61391793526c011d74b1bb1ae50f8`. [Сборочный процесс](https://github.com/Pakka19941311/Pakka/actions/runs/34140841356). [Скачать исправленный Windows ZIP](https://github.com/Pakka19941311/Pakka/releases/download/godot-pc-preview-1dcd61ffd8c6/Varendor_Godot_PC_1dcd61ffd8c6.zip) — 202,210,883 байт. Распаковать и запустить `RUN_VARENDOR.bat`. [Release](https://github.com/Pakka19941311/Pakka/releases/tag/godot-pc-preview-1dcd61ffd8c6). Публичное скачивание проверено без авторизации, SHA-256: `7b2087b23ea6d5468e55520ce49972a202fbfcd2a400b0219dbe1fc39700cdd1`.

Собран native клиент на прежнем сервере, каталогах и Git-ассетах. Blender собирает 604 размещения текущего мира; Godot отображает землю, здания, природу, прежние классы/противников и четырёх NPC. Подключены движение, камера, цель, серверные атаки/умения, HUD, миникарта, 42 ячейки с прокруткой, 12 слотов экипировки, 32 сохраняемых назначения, предметные команды и заточка. Серверные правила, 60 вероятностей, itemId/UID и исходная игра не переписаны.

Запускатель играет в отдельной тестовой базе. Если по известному пути найдена прежняя SQLite, создаётся read-only online backup с проверкой пяти таблиц, полного состояния и UID, затем отдельная игровая копия. Старый файл не используется для записи. Личной SQLite и browser localStorage владельца здесь нет: его резервирование, восстановление и импорт прежних назначений не выполнены. Автоматическое копирование проверяется только на синтетическом мире.

Финальный CI прошёл на точном commit выше: экспортированный Godot под Linux/X11/Mesa отрисовал мир и HUD, поставляемый Windows EXE запущен без графики с portable Node v24.20.0. Проверены 5 классов, 33 определения предметов, вход и движение, перестановка/снятие/экипировка с прежними UID, сохранение 32-й ячейки, одно расходование свитка при повторе receipt после смены процесса/папки пакета и неизменность исходной тестовой базы. Манифест файлов, ZIP CRC, размеры и SHA опубликованных assets совпали. Проверка звука не проводилась; на CI используется Dummy audio.

[Фактический кадр Godot](https://github.com/Pakka19941311/Pakka/releases/download/godot-pc-preview-1dcd61ffd8c6/native-runtime.png) просмотрен: устранён пересвет от физических intensities Blender в относительном режиме Compatibility. Первый пакет `52e5ed89eedc` сохранён как промежуточный; для теста используется новый `1dcd61ffd8c6`. Свет костров приведён к энергии 1 и радиусу 5 м, игровые расчёты не менялись.

Свидетельства: [Linux native](evidence/linux-native-qa.json), [Windows native](evidence/windows-native-qa.json), [публикация](evidence/publication.json). На программном Mesa время кадра: медиана 132.88 мс, p95 144.44 мс; это не профиль видеокарты владельца и не подтверждение целевых FPS.

Ограничения: финальные новые модели/материалы и VFX не завершены; известная повреждённая `colormap.png` части реквизита заменена только в производной сцене цветом материала. P0-ASSET-001 остаётся открыт. Linux/Mesa render не подтверждает Windows GPU/FPS. Общий постоянный онлайн-сервер не развёрнут. P0 и P1–P6 целиком не приняты. Следующий шаг — тест исправленного ZIP на ПК владельца и исправление замечаний текущего блока; Mac/Android не начинать.
