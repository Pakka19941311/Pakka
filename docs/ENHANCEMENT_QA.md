# D — четыре свитка и заточка V2

База: принятый B 589ad13b. Только work/v06-commercial-rebuild; main не меняется.

Содержимое блока: src/core/enhancement-v2.ts — таблица, проверка категорий/версий и атомарный кандидат, выбранные источники дропа, миграция и обмен. Инвентарь — одна активация/одна попытка, подсветка, точная подсказка, отмена. Локальный gateway сохраняет результат до принятия клиентом; сбой записи не тратит предметы. Gates: все 60 сочетаний соответствуют docs/ENHANCEMENT_BALANCE_V2.json; точные RNG-границы, безопасные ступени, несовместимость/предел/смерть/stale refs/дубликаты, уничтожение и единичный расход, таблица дропа и отсутствие старого дропа, перенос старого запаса и full bag, ошибка хранилища. Прежние tests/build/assets/lifecycle обязательны.

scripts/enhancement-regression.mjs: реальный Chromium production и отдельная QA-сборка; двойной клик свиток → один/двойной клик предмет, отсутствие второго equip, все четыре качества, обычный/улучшенный +2 доспехов, уничтожение надетого и сумочного, отмена, cap, stale, пропавший свиток, ошибка записи, смерть, migration/reload. B/C/E/A проверяются на этом же SHA. Windows launcher проверяет HTML/JS/GLB.

Фактические десять JSON и полный SHA входят в ZIP. Software WebGL не доказывает FPS на аппаратном GPU. Пользователь проверяет ощущение и взаимодействие; после выдачи — СТОП до принятия D.
