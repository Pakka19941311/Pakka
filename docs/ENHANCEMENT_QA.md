# D — четыре свитка и заточка V2

База исправления: D ba2b6148 (ожидает пользовательского теста). Только work/v06-commercial-rebuild; main не меняется.

Содержимое блока: src/core/enhancement-v2.ts — таблица, проверка категорий/версий и атомарный кандидат, выбранные источники дропа, архивирование старого типа без обмена. Инвентарь — одна активация/одна попытка, подсветка, точная подсказка, отмена. Локальный gateway сохраняет результат до принятия клиентом; сбой записи не тратит предметы. UI-фикстуры/RNG не входят в production.

Gates: все 60 сочетаний соответствуют docs/ENHANCEMENT_BALANCE_V2.json; точные RNG-границы, безопасные ступени, несовместимость/предел/смерть/stale refs/дубликаты, уничтожение и единичный расход, таблица дропа и отсутствие старого дропа, разовая beta-выдача +100 каждого, сохранение старого запаса без конвертации, full bag/буфер, ошибка хранилища. Прежние tests/build/assets/lifecycle обязательны.

scripts/enhancement-regression.mjs: реальный Chromium production и отдельная QA-сборка; двойной клик свиток → один/двойной клик предмет, отсутствие второго equip, все четыре качества, обычный/улучшенный +2 доспехов, уничтожение надетого и сумочного, отмена, cap, stale, пропавший свиток, ошибка записи, смерть, migration/reload. B/C/E/A проверяются на этом же SHA. Windows launcher проверяет HTML/JS/GLB.

Фактические одиннадцать JSON и полный SHA входят в ZIP. Software WebGL не доказывает FPS на аппаратном GPU. Пользователь проверяет ощущение и взаимодействие; после выдачи — СТОП до принятия D.

Дополнительный gate D-hardcore: сборка VARENDOR_BETA=0 создаёт героя без свитков, после reload выдачи нет. Скачиваемая бета-сборка VARENDOR_BETA=1 выдаёт четыре стака по 100; после расхода/reload запас не восполняется. QA моделирует существующее сохранение: +100 каждого один раз, сохранены UID экипировки, старые вещи и количество; UI обмена отсутствует. Модульные проверки: полная сумка/буфер, переполнение количества, сбой записи и повторный вход.
