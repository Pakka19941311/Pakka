# QA Report — Varendor: Ashen Frontier v0.3

Дата проверки: 2026-09-03.

## Автоматическая проверка

- TypeScript typecheck: пройден.
- Production build Vite: пройден.
- 16 тестов игровых правил и сценариев: пройдены.
- Проверка 5 персонажей, 4 монстров и 21 модели окружения: пройдена.
- Runtime smoke через production HTTP: пройден.
- Загрузка всех GLB/glTF непосредственно Babylon.js: пройдена.
- Анимации всех персонажей и монстров обнаружены Babylon.js: пройдено.

## Проверенные сценарии

- создание персонажа любого из пяти классов;
- расчёт HP/MP/XP и рост уровней;
- движение и выбор цели;
- обычная атака, 20 классовых навыков, AoE, DoT, stun, slow, knockback, leech, guard, vanish и боевой призыв;
- автоматический дроп, стакинг ресурсов и буфер заполненной сумки;
- экипировка без требования уровня и два слота колец;
- безопасная заточка +0 → +3, уничтожение при неудаче выше +3 и отдельные нелинейные кривые усиления оружия/брони;
- Mini RB и трёхфазный Pit Boss;
- NPC-квест, торговец, кузнец и проводник;
- сохранение персонажа, инвентаря, настроек и таймеров боссов;
- миграция локального сохранения v0.2 в v0.3.

## Ограничение среды проверки

Встроенный облачный браузер не открыл локальный игровой адрес, поэтому визуальная GPU-проверка в этой сессии была заменена production runtime smoke, HTTP-проверкой всех файлов и фактической загрузкой каждой модели и анимации движком Babylon.js в headless-режиме. Пользовательский Windows-запуск остаётся частью финального игрового тестирования.
