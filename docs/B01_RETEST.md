# B01 — исправления по отклонённому пользовательскому тесту

Первая сборка `24176515` не принята. Видео 71,66 с: 11–14 FPS, p95 до 243 мс; герой и мобы ниже грунта, потерянное центрирование dock, пересекающиеся дороги и невидимые препятствия. B02 закрыт.

Найденные причины и изменения:
- Деформированный terrain при actor Y=0. Общая треугольная поверхность для опоры, моделей, меток и VFX; ровные основания существующих поселений.
- Все дорожные плоскости имели одну высоту 0,045. Теперь единая геометрия: пересечения дорог объединяются, каждый треугольник принадлежит ровно одному материалу.
- Модуль крепости искался среди glTF rootNodes (__root__), а нужный объект — внутри. Выбирается экспортированный узел со всеми material primitives; pivot центрируется до rotation. Коллизия добавляется по реально созданной геометрии.
- Убрана старая ограда через площадь. Случайные камни/деревья не ставятся на улицах и подходах; расположение декора стабильно при Continue и изменении качества.
- Click-to-move/pursuit героя раньше не использовали навигацию. Теперь используют общий маршрут. Коллизия скользит по нормали препятствия, восстанавливает overlap и не позволяет проскочить тонкую стену длинным шагом; yaw согласован с Babylon.
- Коллизии прилавков, телеги и фонарей были значительно крупнее реальных моделей. Размеры и смещение берутся из загруженной геометрии до поворота; NPC больше не размещаются внутри прилавка/жаровни. Свободная точка возле стены не округляется в занятую клетку навигации.
- Зелья, навыки и меню расположены одним контейнером с автоматическим вписыванием при UI scale. Журнал не пересекается с dock.
- Останавливаются далёкие анимации/визуалы; статические матрицы зафиксированы; маршруты переиспользуются. Раздельные CPU-замеры и сравнение именно с отклонённым B01, без обещания FPS на неизвестном GPU.
- При устойчивой перегрузке существующий governor ограничивает также MSAA, размер теней и bloom; возврат качества медленный, с гистерезисом. Сохранённые пользовательские настройки не перезаписываются. Пустые glTF roots исключены из shadow list. Компиляция теней выполняется штатным render path, без несовместимого с этими материалами forceCompilationAsync.

Последний CPU-профиль обнаружил дорогие последовательные пересоздания drawing buffer во время severe overload. Теперь после устойчивой просадки >50 ms выполняется один переход к ограниченному бюджету, а не четыре промежуточных resize. Отдельный regression test проверяет число переходов.

Новые runtime gates: проход ворот туда/обратно, обход центральных объектов, пути ко всем NPC; skinned bounds относительно грунта на склонах; отсутствие пересечения/обрезки трёх панелей при 1280/1920/3266 и 80/100/125%; зелья по клавише/кнопке до нулевого stack; respawn с корректной высотой.
