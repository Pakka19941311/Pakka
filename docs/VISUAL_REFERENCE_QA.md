# G / B02 — проверка визуального эталона

База: принятый владельцем блок F `7622fb11`. Рабочая ветка — `work/v06-commercial-rebuild`; `main` не меняется. Один результат G объединяет визуальный эталон рыцаря, волка и участка Гринфолл — ближайший лес. После ZIP статус `awaiting_user_test`, остановка до принятия.

Проверка ограничена изменёнными моделями и окружением. Принятые матрицы F/A/B/C/D/E, смерти, респавна, всех классов и заточек повторно через браузер не запускаются. Быстрые модульные тесты, сборка и проверка реальных ресурсов остаются обязательными.

## Обязательные проверки

- Unit-тесты проекта, TypeScript, production build, реальный загрузчик ассетов. NullEngine подтверждает структуру ресурсов; он не подтверждает художественное качество или аппаратную производительность.
- `G-production-visual.json`: один рыцарь в production-сборке, старт нового персонажа и обычное «Продолжить» после reload. Мир и ресурсы загружены, экипировка и сумка сохранены, изменяющих состояние QA-фикстур в скачиваемой игре нет.
- `G-visual.json`: один рыцарь в отдельной QA-сборке. Пять настоящих видов — ворота, двор, лес, рыцарь вблизи, волк вблизи. Геометрия, материалы, видимость, наличие анимационных клипов и фактические границы персонажа проверяются по данным движка. Снимки и диагностические JSON сохраняются для визуального просмотра. Состояние мира фиксируется только для повторяемого кадра; художественные объекты не подменяются тестовыми.
- Один обычный клик мышью по настоящему волку запускает реальную атаку рыцаря. Первый контакт даёт ровно один выпуск атаки и нанесение урона. У обоих моделей загружены риги и выбран действующий клип. Проверяется, что ближние модели видимы, а удалённые монстры скрываются существующей системой дальности.
- Windows launcher: реальный старт PowerShell HTTP-сервера, HTML, JavaScript MIME/маршруты, полный GLB.
- Упаковка допускается только при двух отчётах с точным `GITHUB_SHA`, `passed=true`, пустыми `errors` и непустыми `checks`. Игра содержит production-файлы, launcher, инструкцию, актуальное ТЗ, описание эталона, лицензии, отчёты и полный SHA. Проверяются целостность ZIP и SHA-256. Скриншоты находятся в отдельном QA-asset того же Release.

## Условия и границы доказательств

Браузер: Chromium software WebGL, 1280×720. Для пяти фиксированных художественных видов запрашиваются High и масштаб 100%; фактический размер рендера и состояние адаптивного качества записываются в отчёт. Короткие проверки production и контакта используют Low/50%, чтобы программный стенд не задерживал проверку ввода. Автоматическая готовность материалов и геометрические границы не оценивают красоту кадра: изображения требуют просмотра, а окончательное принятие вида принадлежит владельцу. Программный WebGL не является замером FPS на видеокарте игрока.

Фактический результат выпуска и ссылка на CI дописываются ниже только после успешного завершения обязательных проверок и упаковки.
