VARENDOR — B01 PERFORMANCE TEST

1. Закройте окно сервера предыдущей сборки, если оно запущено.
2. Распакуйте ВЕСЬ ZIP в отдельную папку. Не запускайте файл внутри ZIP.
3. Дважды нажмите RUN_VARENDOR.bat. Откроется браузер с игрой.
4. Не закрывайте чёрное окно сервера, пока играете.
Установка Node.js, Python, Unity или Blender НЕ требуется.

Адрес: http://localhost:4173/
Прогресс хранится в браузере, как раньше. Используйте тот же браузер.

Эта сборка проверяет отзывчивость и стабильность, не новый художественный стиль.
Показатель сверху: FPS, p95 (длительность худших 5% кадров), размер 3D-рендера.
При перегрузке разрешение 3D плавно снижается. Размер текста/UI не уменьшается.
Проверьте бег/WASD, ПКМ/камеру, колесо, бой, NPC, повторный вход.
Для отчёта полезны ваш FPS/p95, выбранное качество и название видеокарты.
Следующий блок не начинается до вашего принятия этого теста.
