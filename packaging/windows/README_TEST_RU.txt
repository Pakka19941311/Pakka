VARENDOR: ASHEN FRONTIER — v0.5 CORE QUALITY REBUILD
WINDOWS TEST BUILD

Как запустить:
1. Полностью распакуйте ZIP в отдельную папку.
2. Дважды нажмите RUN_VARENDOR_v0.5_WINDOWS.bat.
3. Игра автоматически откроется в браузере.
4. Не закрывайте окно PowerShell во время игры.

Управление:
- WASD — движение относительно камеры.
- ЛКМ по земле — click-to-move и отмена преследования.
- ЛКМ по монстру — выбор цели, подход и обычная атака.
- ПКМ + движение мыши — вращение камеры.
- Колесо мыши — приближение и отдаление.
- Space — прыжок.
- 1–4 — навыки.
- Q / E — расходники по умолчанию; клавиши меняются в настройках.
