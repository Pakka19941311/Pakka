VARENDOR — ЧАСТЬ 1. ТЕСТ МИРА И ОКРУЖЕНИЯ

ЗАПУСК
1. Закройте окно сервера предыдущей сборки.
2. Полностью распакуйте новый ZIP в отдельную папку.
3. Откройте RUN_VARENDOR.bat. Установка Node.js и npm не нужна.
4. Игра откроется в вашем браузере: http://localhost:4173/
5. Для прежнего героя используйте тот же браузер и его прежний профиль.
   Старое браузерное сохранение остаётся на месте; предусмотрен однократный
   перенос в тестовый сервер с резервной копией. Если сохранения не видно,
   проверьте профиль браузера и точный адрес localhost:4173, не создавайте
   нового героя вместо нужного сохранения.

КАК ЖИВЁТ МИР
Окно сервера оставляйте открытым. Вкладку игры можно свернуть или закрыть:
сервер продолжает отсчитывать время и выполнять игровые события.
Герой после потери связи остаётся уязвимым 30 секунд.
Для штатной остановки в окне сервера введите stop и нажмите Enter
или нажмите Ctrl+C. После этого прогресс сохранится.
Это локальный тестовый сервер на вашем ПК. При выключении, сне ПК
или закрытии окна сервера процесс прекращает работу. Внешнее размещение
24/7 и доступ друзей через интернет эта сборка не объявляет готовыми.

СОХРАНЕНИЯ
Мир хранится отдельно от распакованной игры:
%LOCALAPPDATA%\Varendor\world-beta-v1\world.sqlite
Поэтому следующий ZIP можно распаковать в новую папку без потери мира.
Не удаляйте эту папку для обновления. Для резервной копии остановите
сервер командой stop и скопируйте всю папку world-beta-v1.
Перенос старого сохранения разрешён только в этой частной тестовой среде;
это не импорт имущества в будущую публичную игровую экономику.

ЕСЛИ ЗАПУСК НЕ УДАЛСЯ
Если порт занят, закройте старое окно сервера и запустите новый ещё раз.
Если браузер не открылся сам, откройте http://localhost:4173/ вручную.
Не запускайте index.html двойным кликом и не меняйте адрес на другой порт.
При ошибке пришлите текст из окна сервера и BUILD_COMMIT.txt из папки игры.

Герои, NPC и монстры обновляются в следующих отдельных частях после
принятия мира. Конкретный список проверки этого кандидата приходит
вместе с прямой ссылкой на GitHub Release.
