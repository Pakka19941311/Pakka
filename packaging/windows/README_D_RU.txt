VARENDOR — Enhancement D Windows Test

Распакуйте ZIP целиком в отдельную папку. Запустите RUN_VARENDOR.bat.
Сохранение героя остаётся доступным через «Продолжить» при том же адресе браузера.

Tab — сумка. Двойной клик по свитку → наведите на подсвеченную вещь, прочитайте шанс → один клик по вещи выполняет одну попытку. Следующая попытка требует снова активировать свиток. При неудаче на небезопасной ступени предмет уничтожается полностью. Без дополнительного модального подтверждения.

Оружие: до +3 безопасно. +3→+4 обычный 50%, улучшенный 75%; на +9 — 13%/17%; на +15 — 3%/5%.
Доспехи (включая украшения, щит/фокус): +1 безопасно обоими. На +2 обычный 65%, улучшенный 100%. На +3 оба рискованные. Максимум +15.

Esc или ПКМ внутри инвентаря отменяет выбор бесплатно. Tab закрывает окно и отменяет выбор. Неправильная категория/предел/смерть не расходуют свиток. Улучшенный даёт повышенный шанс, но не страховку. Мир продолжает жить.

Старые универсальные свитки перенесены в отдельный запас: кнопки «1 → оружие» и «1 → доспехи» под сумкой обменивают по одной единице 1:1. Остаток сохраняется. При полной сумке без подходящего stack сначала освободите ячейку. До миграции хранится резерв исходного save.

Новые свитки падают только с выбранных монстров. Оружие: изгнанник, сектант; доспехи: мертвец, рудокоп, призрак; боссы — обе категории. Улучшенные в 10 раз реже обычных. Свитки не продаются бесконечно в лавке. Бран открывает ту же систему в сумке.

BUILD_COMMIT.txt — SHA, QA_REPORT_RU.md и JSON — проверки. После пользовательского теста ожидается принятие D; следующий блок не начинается заранее.
