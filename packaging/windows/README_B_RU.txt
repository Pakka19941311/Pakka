VARENDOR — HUD B Windows Test

Распакуйте ZIP целиком в отдельную папку. Запустите RUN_VARENDOR.bat.
Не запускайте dist/index.html напрямую. Сохранение предыдущего героя доступно через «Продолжить» при том же адресе браузера.

Блок B: здоровье, ресурс и опыт снизу; миникарта слева сверху; выбранная цель сверху; действующие эффекты с таймером справа. Журнал имеет фильтры. Поле ввода — локальные заметки, не сетевой чат.

Панель содержит 8 ячеек в ряду, по умолчанию 2 ряда. «4 ряда» раскрывает дополнительные. «Настроить» → ячейка → действие/клавиша → «Назначить»; снова нажмите «Настроить» для выхода. Точка на кнопке раскрытия означает заполненные скрытые ряды.

1–8 / Shift+1–8 — быстрые ряды. Q/E — зелья, ранее изменённые назначения сохраняются. Запас общий с сумкой: пустое назначение остаётся после расхода последней единицы и работает после пополнения. Двойной клик расходует одну единицу.

Tab — компактная сумка. Наведение — характеристики и сравнение; двойной клик — надеть/снять/использовать. Заточка V2 ещё не внедрена: старые свитки используются у Брана.

Проверьте бой, Q/E, масштаб, настройку дополнительного ряда и сохранение после перезагрузки. Следующий блок начинается только после вашего принятия B.

BUILD_COMMIT.txt содержит точный SHA. QA_REPORT_RU.md и JSON — технические результаты. CI software WebGL не измеряет FPS вашего компьютера.
